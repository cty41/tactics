# Task7: 战斗反馈优化

## 目标

提升战斗的视觉和听觉反馈，让玩家清晰感知每一次决策的结果。

---

## 输入

- 现有的 `BattleUIController`
- 战斗日志系统（`BattleLogger`）
- `Unit` 和 `CombatComponent`

---

## 输出

### 1. 伤害数字飘字

**触发时机**：单位受到伤害、治疗、Miss 时。

**显示规则**：

| 事件 | 显示方式 |
|------|----------|
| **普通伤害** | 白色数字，从受击单位头顶向上飘动 |
| **暴击伤害** | 红色加粗大数字，带缩放动画 |
| **Miss** | 灰色"Miss"文本 |
| **治疗** | 绿色数字，向上飘动 |
| **DoT 伤害** | 较小字体，紫色数字 |

**技术要点**：
- 在 `Unit` 头顶位置生成世界空间 Canvas 或 Billboard 文本
- 动画：向上飘动 + 淡出，持续 1-2 秒
- 暴击可附加屏幕震动或放大效果

### 2. 战斗日志 UI

**位置**：Battle UI 底部或侧边，滚动日志面板。

**内容格式**：
- "[攻击者] 对 [目标] 造成了 [伤害] 点伤害（暴击！）"
- "[目标] 受到了 [Buff名称] 效果，持续 [N] 回合"
- "[目标] 的 [Buff名称] 效果结束了"

**交互**：
- 自动滚动到最新日志
- 可展开/收起面板
- 最多保留最近 50 条日志

### 3. 镜头反馈

**触发时机**：
- 暴击：轻微镜头抖动（Camera Shake），持续 0.2-0.3 秒
- 击杀：更强烈的镜头抖动 + 短暂时间缩放（Time Scale 降至 0.3，持续 0.5 秒）

**实现方式**：
- 使用 Cinemachine Impulse 或自定义 Camera Shake 脚本
- 通过 `BattleFlowCoordinator` 或事件系统触发

### 4. 状态提示

**Buff 施加/消失提示**：
- Buff 施加时：单位头顶显示 Buff 图标，带"+"号动画
- Buff 消失时：图标带"-"号动画淡出
- 持续 Buff 的图标常驻在 Unit UI 上

---

## 核心代码改动

| 文件 | 改动 |
|------|------|
| `BattleUIController` | 新增飘字生成方法、日志面板 |
| `DamageNumberController` | 新建：伤害数字动画控制器 |
| `BattleLogPanel` | 新建：战斗日志 UI 组件 |
| `CameraShakeController` | 新建：镜头抖动控制器 |
| `CombatComponent` | 伤害计算后触发飘字和日志事件 |
| `BuffComponent` | Buff 施加/移除时触发图标提示 |

---

## 验收标准

1. 每次攻击/治疗都有明确的数字飘字和日志记录。
2. 暴击和击杀有更强的视觉反馈（抖动、放大、特殊颜色）。
3. Buff 施加和消失时有图标动画提示。

---

## 风险与注意事项

1. **性能**：大量飘字同时出现时需要对象池管理，避免频繁 GC
2. **世界空间 UI**：飘字使用世界空间 Canvas 时需要注意相机距离导致的缩放问题
3. **无障碍**：考虑为视觉反馈添加对应的音频反馈（暴击音效、击杀音效）
