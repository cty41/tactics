# Pure Run 墓穴大嘴蝠风刃动作姿态设计

## 目标

为墓穴大嘴蝠制作一张 `down-right` 单帧远程攻击姿态探针，用翅膀完成强力下拍来表达风刃释放。该探针只验证角色动作语言、球核稳定性和翼部三维关系；本阶段不制作 `up-left`、施法、受击或死亡姿态，也不接入 Godot 运行时。

## 真相源与输入职责

- 唯一角色母图：`Tools/artworks/pure_run/enemies/approved/tomb_maw_bat_ranged_color_v06.png`。
- 母图锁定球核尺寸与中心、悬浮高度、脸部身份、配色、线宽和 `down-right` 等距朝向。
- `Tools/artworks/pure_run/enemies/approved/tomb_maw_bat_ranged_color_ul_v01.png` 只用于理解既有背向结构，本轮不作为 DR 生成输入。
- `rejected`、`superseded`、死亡候选和 Review 快照只能用于识别失败模式，不得作为 ImageGen 输入或后续编辑起点。

## 动作设计

姿态取风刃刚释放的拍击瞬间，而不是蓄力抬翼：

- 近侧大翼向前下方猛烈横扫，成为主要力量线。
- 远侧翼停留在后上方，形成明确的不对称扭转和三维纵深。
- 球核只允许约 `5–8°` 的轻微反向旋转；不得前冲、下沉或贴近虚拟基线。
- 球核可以产生极轻微的受力压缩，但不得变成长椭圆、胶囊体或按完整翼展重新缩放。
- 眼睛朝向攻击目标并表现专注、凶狠；嘴保持闭合或咬紧，不能被理解为口部喷射。
- Sprite 内不绘制风刃、气流、速度线、投射物、阴影、文字或地面。风刃以后由独立投射物或 VFX 表达。

## 飞行单位构图契约

- 输出为 `256×256 RGBA`；球核水平中心固定在 `x=128`。
- 球核尺寸、中心与悬浮高度以正式 DR 母图为唯一体量锚点；翅膀不参与缩放或水平居中。
- 虚拟落点保持 `(128,236)`，并与球核中心、目标 Tile 中心处于同一垂直轴线。
- 翼尖必须完整留在画布安全边距内；若完整外轮廓超出发布容差，只能作为候选记录，不能通过缩小球核补救。
- 制作 `128×128` Mitchell 等比预览，虚拟落点为 `(64,118)`；Tile Review 必须复现 `64×32` 错列等距格心。

## 生产与审核顺序

1. 从正式 DR 母图制作只包含球核的测量蒙版，排除耳朵、眼睛、嘴和双翼。
2. 单独生成一张纯色幕 DR 动作候选，完成去幕、透明边缘与四角检查。
3. 对比母图和候选的球核中心、最大宽度、上下缘与悬浮高度；球核不合格时回到正式母图重新生成，不在错误候选上继续编辑。
4. 生成透明 `256×256` 候选、同名 `_128` 预览和 Tile Review，等待人工审核。
5. 只有 DR 获得明确批准后，才另行设计并原生生成 `up-left`。UL 必须保持同一近水平风刃攻击轴，不能变成向上扇击，也不能镜像 DR 冒充背向图。
6. DR/UL 都批准后再决定是否创建飞行单位专用 Tween/Profile 和运行时试玩切片。

## 验收标准

- 在 `128×128` 预览中，不看风刃 VFX 也能读出一次强力翅膀拍击，而不是普通滑翔或受击失衡。
- 球核身份、尺寸、中心和悬浮高度与正式 DR 母图一致，没有因翼展产生缩小、下沉或横向漂移。
- 近侧翼、球核与远侧翼的遮挡关系自然，没有翅膀断裂、额外翼、翼膜穿体或前后层颠倒。
- 闭嘴与视线明确排除口部喷射语义。
- 画面中不存在烘焙风刃、粒子、阴影、地面或文字。
- 透明边缘无绿色或洋红色残留，四角 alpha 为零，虚拟落点与 Tile 中心对齐。

## 已批准 DR 锚点

用户已批准 `Tools/artworks/pure_run/enemies/approved/tomb_maw_bat_wind_blade_attack_dr_v03.png` 作为风刃动作的 DR 锚点，对应 `_128` 预览为同目录的 `tomb_maw_bat_wind_blade_attack_dr_v03_128.png`；该版本已于 2026-08-06 从 `candidates` 升级为正式图，作为当前生成状态下的临时收尾，`up-left` 与运行时接入均留待后续。该版本采用双翼同步横扫：近翼保持可接受的透视放大，远翼也参与同一攻击阶段；后续 UL 必须以这张图锁定动作强度和近水平攻击轴，但仍需从正式 UL idle 母图原生生成，不能镜像 DR。

## 边界

- 本设计不生成 `Cast`、`Hit`、死亡图或逐帧翅膀动画。
- 本设计不创建蝙蝠 Prefab，不修改 AI、技能、投射物、VFX、伤害时序或现有地面 Tween。
- 蝙蝠不能直接复用 `StandardUnitTweenProfile`；未来运行时接入必须单独设计悬浮、阴影与翼展安全范围。
- 未经人工批准的候选只保存在 `Tools/artworks` 的设计层目录，不得进入 `godot/assets`。
