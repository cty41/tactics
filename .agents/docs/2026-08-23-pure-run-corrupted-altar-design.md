# Pure Run 堕落祭坛美术设计

## 目标

为 Pure Run Adventure Board 制作一个可交互的堕落祭坛场景资产。祭坛必须明显大于普通单位，并延续项目现有的“犬类头部、直立胶囊体、短小四肢”造型语言，不能表现为写实犬类雕像或普通单格道具。

## 空间规格

- 祭坛整体占据 `2×2` Tile，视觉占地约为四个普通单位格。
- 使用与现有 Tile 道具一致的 DR 斜俯视方向。
- 后方神像、底座和前方祭品石台作为一个完整透明背景资产输出。
- 最终画布尺寸、锚点和运行时落点需要在资产实现阶段依据 `2×2` Tile 几何重新定义；不得沿用原单 Tile 的 `256×256`、`y=236` 合同。

## 主体造型

- 后方中央设置一尊巨型犬神石像。
- 神像保持现有角色体系的直立胶囊体身体、犬类头部和短小四肢。
- 犬首采用泛化的中华田园犬特征：三角立耳、适中口鼻，不使用特定角色的花色、服饰或饰品。
- 神像视觉高度约为普通胶囊体单位的 `1.6–2` 倍。
- 神像站在低矮、宽厚的石质底座上，避免被理解为单纯放大的石化角色。

## 祭品石台

- 神像正前方设置独立的矮石台，构成清楚的前后层次。
- 石台保持空置，不内置骨头、蜡烛或其他祭品。
- 石台不得遮挡神像的胶囊体轮廓和主要破损特征。
- 空石台为后续事件按需叠加不同祭品预留空间。

## 残破与腐化

- 神像缺失一只前爪，断面清楚可读。
- 身体和底座包含少量明显裂缝、崩角与风化痕迹。
- 犬首保持基本完整，不采用缺失半个头部的方案，以保留远距离犬类辨识度。
- 暗紫色腐化微光仅出现在部分裂缝、断面和石台刻纹中。
- 不使用大型法阵、烟雾、粒子、外溢光环或其他抢占主体的特效。

## 构图与风格

- 采用正面神龛式构图：神像位于后方中央，石台位于前方中央，整体近似对称。
- 通过缺失单侧前爪和局部崩损形成有限的不对称感。
- 使用粗深色外轮廓、简洁色块和有限内部线条，与现有胶囊体角色和已批准 Tile 道具保持一致。
- 石材以中性深灰为主，暗紫色仅作为受控强调色。
- 不添加地面、投影、文字、水印或 UI 元素。

## 验收标准

- 缩小到地图实际显示尺度时，首先能读出“巨型胶囊犬神像＋前方祭品台”。
- 与普通单位并置时，整体占地和高度均明显更大，不会被误认为单 Tile 角色或普通摆件。
- 中华田园犬的泛化犬类轮廓清楚，但不指向某个已有角色。
- 缺失前爪和身体裂缝清楚可见，同时不会破坏主体识别。
- 前方石台保持空置，且拥有足够清楚的台面供后续叠加祭品。
- 腐化感来自局部暗紫裂纹与刻纹，而不是大型法阵或复杂特效。

## 实现边界

- 本设计只定义祭坛美术资产，不包含祭品变体、交互逻辑、碰撞、Tile 占位或运行时场景接入。
- 后续实现必须先替换原 `prop-altar` 单 Tile 合同和提示词，再生成候选并走 Pure Run artwork pipeline 的 Review、用户确认与 promote。
