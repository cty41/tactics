# 魔剑士 Cast DR：无光效举剑姿态

## 目标

Cast DR 是 Demonbound 施放/聚焦时使用的角色 Sprite。它只表达角色姿态与祖传宝剑的物理位置；剑尖聚能、闪光和技能释放均不画进 Sprite。

## 固定视觉合同

- 视角为 down-right 三分之四角，身份、核心体量、脚底基线和半身异色均以正式 Idle DR 为锚点。
- 主体是近乎竖直、等宽且刚性的胶囊体；禁止梨形、下半身外扩、手臂和腿。
- 恰有四只贴身爪：两只脚爪稳定落地；两只手爪在胸口中线、剑柄左右两侧夹持。双手持剑只是一张 Cast 姿态的例外，不把祖传单手剑改定义成双手大剑。
- 紧凑的祖传诅咒单手剑沿角色自身中线竖举。剑刃窄，只穿过面部中央窄带；护手位于口鼻下方、领圈上方，不能遮住任一眼睛。剑尖高于双耳但保留画布安全边距。
- 头部微抬，双眼朝剑尖仰视，表情严肃、专注。保留灰白额斑、一只异色耳和半身异色；额斑是犬毛色，不是人类发型。
- 剑鞘必须不存在。Sprite 内不得含静态辉光、光球、光柱、火焰、粒子、半月斩或其他魔法特效。

## 参考与生产边界

外部截图只用于提炼“双手中线竖举宝剑”的姿态语言，不复制、不入库、不作为 ImageGen 输入。实际生成输入只可包含正式 Idle DR 与项目自有的确定性 pose guide。

验收时，语义蒙版需登记 core、near/far hand、near/far foot、equipment 和双耳；annotations 需登记双眼区域、护手框、剑轴/出口、剑尖、中线遮挡带与宝石框。正式晋升仍须通过 Artwork 合同状态机与 `cty41` 人工 approval。
