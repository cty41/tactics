## 战术角色扮演游戏 - 属性系统设计文档

### 1. 设计哲学

- **数值透明**：玩家能清楚知道提升某属性会带来什么具体战斗收益（HP、MP、Speed、Damage 的变动可预测）
- **分层计算**：一阶属性（六维）通过固定公式推导为二阶战斗属性，确保 Build 方向明确
- **平滑过渡**：Action Points 当前保留但计划弃用，文档需说明其现状与替代方向

---

### 2. 基础属性（一阶属性）

六大基础属性为角色成长的根基，通过固定公式转化为二阶战斗属性。

| 属性 | 定位 | 影响的二阶属性 |
|------|------|---------------|
| 力量（Strength） | 近战物理输出核心 | 近战伤害 |
| 敏捷（Agility） | 远程物理输出与机动性 | 远程伤害、Speed |
| 体质（Constitution） | 生存能力 | 最大生命值（HP） |
| 智力（Intelligence） | 资源管理与技能频率 | 法力回复、技能释放频率 |
| 魅力（Charisma） | 法力池与特殊能力 | 最大法力值（MP） |
| 幸运（Luck） | 随机性调节与暴击 | 暴击率 |

**数值基准**：所有基础属性的基准值为 5（普通水平）。属性值围绕 5 波动，高于 5 获得正加成，低于 5 获得负加成。

---

### 3. 二阶战斗属性

二阶属性由一阶属性推导而来，直接参与战斗结算。

#### 3.1 生命值（HP）

- **计算公式**：`最大 HP = 体质 x 4`
- **战斗作用**：
  - 角色存活的基础，HP 降至 0 时角色退场
  - 高体质角色拥有更高的容错率，能承受更多伤害
- **回复机制**：战斗外通过道具/休息回复；战斗中通过技能/道具回复

#### 3.2 法力值（MP）

- **计算公式**：`最大 MP = 魅力 x 3`
- **战斗作用**：
  - 释放技能消耗的资源，不同技能消耗不同 MP
  - 高魅力角色拥有更大的"技能储备"，能释放更多高消耗技能
- **回复机制**：每回合自动回复 `智力值` 点 MP。高智力角色能更频繁释放技能，低智力角色需要精打细算

#### 3.3 速度（Speed）

- **计算公式**：`Speed = 敏捷值`（直接映射）
- **战斗作用**：
  - **行动顺序**：战斗开始时，所有单位按 Speed 降序排列决定行动顺序。Speed 越高，越早行动
  - **移动力**：`最大移动力 = Speed`（当前版本）
  - 先手压制：高 Speed 角色能抢先治疗、控制或击杀关键目标
- **回复机制**：每回合开始时移动力恢复至最大值

#### 3.4 伤害（Damage）

伤害分为**基础伤害**和**属性加成**两部分：

- **基础伤害**：由攻击系数（Attack Factor）决定，代表角色固有的基础输出能力
- **属性加成**：
  - 近战攻击：`（力量 - 5）x 系数`
  - 远程攻击：`（敏捷 - 5）/ 2 x 系数`
- **最终伤害**：`max（基础伤害 + 属性加成 - 防御系数, 1）`
  - 最低保留 1 点伤害，避免"完全无伤"造成战斗拖沓

**暴击系统**：
- 基准暴击率：10%
- 幸运加成：每点超出 5 的幸运 +2% 暴击率
- 暴击倍率：2 倍伤害

#### 3.5 行动点（Action Points）

**当前状态**：
- 当前版本中 Action Points 作为独立属性存在，用于限制单位每回合的行动次数
- 与 Speed 和移动力并行运作，增加了系统复杂度

**弃用计划**：
- **原因**：Action Points 与 Speed/移动力系统功能重叠，且增加了玩家的认知负担。同一回合内"能走几步"和"能做几个动作"分开计算，导致策略选择不够直观
- **替代方案**：
  - 将 Action Points 的功能合并到 Speed 属性中
  - Speed 同时决定行动顺序、移动力和每回合可执行的行动次数
  - 简化后，玩家只需关注 Speed 一个属性即可理解角色的行动能力
- **迁移路径**：
  - 阶段 1：停止在新内容中使用 Action Points
  - 阶段 2：将现有角色的 Action Points 值合并到 Speed 计算中
  - 阶段 3：从 UI 和文档中移除 Action Points 展示

---

### 4. 属性计算流程

```
基础属性（六维）
    + 装备加成
    ──→ 最终基础属性
    ──→ 二阶属性计算
        - HP  = 体质 x 4
        - MP  = 魅力 x 3
        - Speed = 敏捷
        - 近战伤害加成 = (力量 - 5) x 系数
        - 远程伤害加成 = (敏捷 - 5) / 2 x 系数
        - 暴击率 = 10% + (幸运 - 5) x 2%
```

---

### 5. 数值平衡基准

| 项目 | 基准值 | 说明 |
|------|--------|------|
| 基础属性 | 5 | 普通水平，提供 0 加成 |
| 属性加成系数 | 1.0 | 标准伤害计算系数 |
| 最低伤害 | 1 | 确保每击都有反馈 |
| 暴击倍率 | 2.0 | 暴击造成双倍伤害 |
| 暴击率上限 | 100% | 理论上可达，实际需大量投资 |

---

### 6. 总结

本属性系统采用**一阶属性 → 二阶属性 → 战斗结算**的三层结构：

1. **一阶属性**（六维）：角色成长的根基，玩家直接投入资源提升
2. **二阶属性**（HP/MP/Speed/Damage）：通过固定公式推导，确保数值透明
3. **战斗结算**：基于二阶属性进行伤害计算、行动排序和资源消耗

**当前重点**：Action Points 正处于弃用过渡期，未来将合并到 Speed 属性中，简化系统复杂度。
