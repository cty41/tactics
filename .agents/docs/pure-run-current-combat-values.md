# Pure Run 当前战斗数值总览

更新时间：2026-07-27。本文是下一轮数值讨论的只读基线，来自当前运行时代码、已发布 SkillGraph/AbilityConfig 与正式怪物预制体；“原始伤害”不等于最终伤害预览。

## 角色通用基线

Pure Run 的法师、死灵法师与亚马逊初始六维均为 5（力量、敏捷、体质、智力、魅力、幸运）。

| 项目 | 当前规则 | 初始结果 |
| --- | --- | --- |
| 最大 HP | `体质 × 4` | 20 |
| 最大 MP | `魅力 × 3` | 15 |
| 移动 / 速度 | 单位初始值 | 5 / 5 |
| 回合结束回蓝 | 智力，不超过最大 MP | 5 |
| 战后恢复 | HP `体质 × 2`；MP `魅力` | +10 HP / +5 MP |
| 普攻原始伤害 | 近战：攻击系数 + `力量 - 5`；远程：攻击系数 + `floor((敏捷 - 5)/2)`；最低 1 | 初始攻击系数为 1 时为 1 |
| 暴击 | 基础 10%；幸运每超过 5 点 +2%；伤害 ×2 | 10% |
| 闪避 | 敏捷每超过 5 点 +2%，再与能力闪避/命中惩罚相乘 | 0% |

当前绝大多数职业技能是固定原始伤害。本次没有启用或写入“法师智力、骨矛魅力、亚马逊敏捷”伤害公式。

## 实际伤害修正顺序

有来源的直接伤害依次为：命中/闪避（及受击前冻结阻断）→ 遭遇输出倍率 → 暴击（允许时）→ 受击前钩子 → 防御减法（可绕过）→ 伤害加深 ×1.3 → 所有减伤 Buff 乘法 → 护盾吸收 → 扣血与受伤后钩子。

持续伤害不走直接攻击的闪避/暴击；成功附加后的 DoT 每次以固定原始值结算并绕过防御。范围直接伤害仍可闪避；命中后才附加的 DoT 仅在初次命中成功时添加。
