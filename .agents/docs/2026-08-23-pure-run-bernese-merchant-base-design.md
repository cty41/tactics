# Pure Run 伯恩山犬商人身份母图设计

## 目标

为 Pure Run 场景商人建立一张不依赖服装或道具的犬类身份母图。首轮只验证伯恩山犬特征、标准胶囊体结构和沉稳可信的角色气质；商人服饰、货物与交易反馈姿态不在本轮范围内。

## 角色定位

- 犬种：伯恩山犬。
- 身份气质：老练、沉稳、友善、可信赖的旅行商人。
- 表情：眼神放松，闭嘴，嘴角轻微上扬。
- 禁止表现为困倦、悲伤、奸诈或夸张热情。

## 身体与视角契约

- 使用 Pure Run 标准刚性胶囊体：圆形顶盖、近似平行侧壁、下段持平或轻微内收。
- 不画人形躯干，不画手臂和腿。
- 四只短爪直接与胶囊边缘形成多像素连接，不得浮空或使用细线连接。
- 采用右下 `45°` 等距视角。
- 母版为 `256×256 RGBA`，核心中心位于 `x=128`，最低可见脚爪像素对齐 `y=236`。
- 可见主体高度以项目标准胶囊单位约 `122 px` 为基准；犬耳等外轮廓不得改变核心体量。

## 伯恩山犬身份特征

- 黑色为头部和身体的主体毛色。
- 额头到口鼻保留连续、清楚但不过宽的白色中线。
- 口鼻两侧、眉点与四爪使用暖棕色。
- 胸前可保留小面积白毛，但不得扩展成服装或围巾形状。
- 耳朵短而自然下垂，贴近头部两侧；不得使用巴吉度式长垂耳。
- 口鼻宽厚、圆润，保持温和犬类轮廓，不做人类鼻嘴或胡须。
- 在 `128×128` 预览中，无需装备仍应读作伯恩山犬，并与赤柴角色明显区分。

## 首轮明确排除

- 不添加斗篷、兜帽、围裙、项圈或其他服饰。
- 不添加腰包、背包、货袋、卷毯、金币、账本或商品。
- 不添加武器、法术、招牌、地面、阴影、文字、UI 或场景背景。
- 不制作交易反馈姿态、背向图、动作图或运行时接入。

## 美术语言

- 粗深色外轮廓、扁平纯色块、稀疏内部结构线和清晰抗锯齿边缘。
- 不使用渐变、柔光、镜面高光、3D 体积光或像素噪点。
- 背景透明；若生成阶段使用绿幕，图形内部不得包含近似色幕绿。

## 验收标准

1. 身体是标准等宽胶囊体，不是人形、梨形或自然犬四足体。
2. 无手臂、无腿，四爪与胶囊边缘保持连续接触。
3. 右下三分之四视角和脚底基线正确。
4. 黑、白、暖棕三色分区能稳定表达伯恩山犬身份。
5. 表情沉稳友善，闭嘴且只有轻微笑意。
6. 无任何服装、职业道具或场景元素。
7. `128×128` 与 `64×32` Tile Review 中轮廓和面部标记仍清楚。

## 后续边界

身份母图经用户确认并进入正式资产管线后，才讨论商人服装与货物组件。后续装备不得遮挡白色额纹、暖棕眉点和短垂耳这三项主要身份锚点。
