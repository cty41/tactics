# Task6: 地形效果（基础版）

## 目标

让战场地形成为策略决策的一部分。

---

## 输入

- 现有的 `Cell` / `ICell` 接口
- `Tilemap` 系统
- `CombatComponent`
- `MoveComponent`

---

## 输出

### 1. TerrainType 枚举

为 `Cell` 新增地形类型：

| 地形 | 效果 |
|------|------|
| **平地** | 无特殊效果（默认） |
| **草地** | 无特殊效果 |
| **水面** | 移动力消耗 +1；火焰技能命中后产生蒸汽（遮挡视野一回合） |
| **火焰地表** | 每回合开始时对站立单位造成小额伤害；水系技能可熄灭 |
| **高地** | 攻击低地目标时伤害 +20%；被低地攻击时伤害 -10% |
| **沼泽** | 移动力消耗翻倍；有概率被困住（本回合无法移动） |

### 2. 地形数据初始化

- `UnityCellManager` 从 `DataLayer` Tilemap 读取地形数据
- 根据 Tile 的自定义属性或特定 Tile 类型映射到 `TerrainType`
- 初始化时设置 `Cell.TerrainType`

### 3. 地形影响逻辑

#### 3.1 移动影响

`MoveComponent` 计算移动力消耗时：
- 读取路径上每个 `Cell` 的 `TerrainType`
- 水面：消耗 +1
- 沼泽：消耗 x2
- 沼泽陷阱判定：移动到沼泽格时概率触发"被困住"

#### 3.2 战斗影响

`CombatComponent` 计算伤害时：
- 读取攻击者和目标的 `Cell.TerrainType`
- 高地攻击低地：伤害 x1.2
- 低地攻击高地：伤害 x0.9

#### 3.3 回合开始影响

`Unit.OnTurnStart` 或 `BuffComponent` 中：
- 检查当前站立格子的 `TerrainType`
- 火焰地表：造成小额伤害（可通过 DoT Buff 实现）

#### 3.4 技能与地形交互

- 火系技能命中水面格子：产生蒸汽效果（可简化为施加一个"视野遮挡"Buff）
- 水系技能命中火焰地表格子：熄灭火焰，将该格地形恢复为平地

---

## 核心代码改动

| 文件 | 改动 |
|------|------|
| `Cell.cs` / `ICell.cs` | 新增 `TerrainType` 字段 |
| `UnityCellManager.cs` | 从 Tilemap 读取并初始化地形数据 |
| `CombatComponent.cs` | 地形高低差加成计算 |
| `MoveComponent.cs` | 地形移动力消耗计算；沼泽陷阱判定 |
| `Unit.cs` | 回合开始时检查火焰地表伤害 |

---

## 验收标准

1. **火焰地表**：单位站在火焰地表上时，每回合开始自动扣血。
2. **高地优势**：高地单位攻击低地单位时，伤害数字比平常高 20%。
3. **沼泽移动**：进入沼泽格后移动力消耗翻倍，有概率本回合无法继续移动。

---

## 风险与注意事项

1. **Tilemap 数据**：需要确认现有 Tilemap 是否有足够的自定义属性来标识地形类型
2. **AI 适配**：AI 需要理解地形效果（如优先占领高地、避开火焰地表）
3. **地形与击退**：KnockbackEffect 将目标击退到火焰地表时，应触发火焰伤害
4. **数据兼容性**：`Cell` 新增字段不会影响现有序列化（Cell 通常为运行时生成）
