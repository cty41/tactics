# Task2: 职业技能差异化（修订版）

## 核心原则

- **不添加职业资源系统**（无怒气/充能/标记层数）
- **不添加属性加成伤害计算**（保持现有力量/敏捷近战/远程加成不变）
- **差异体现在**：技能效果设计 + 元素类型机制
- **野蛮人**：近战物理伤害 + 击退/反击技能效果
- **猎人**：远程物理伤害 + 标记/精准射击技能效果
- **法师**：元素法术伤害 + 冰冻/火球技能效果

---

## 开发内容

### 1. 元素类型与破冰系统

代码中使用 `ElementType` 枚举（非 `DamageType`）来标识伤害元素属性：
- `None`：无元素（默认）
- `Fire`：火焰伤害
- `Ice`：冰霜伤害

**破冰机制**：火系伤害命中冰冻目标时，自动移除 `FrozenBuff`，然后正常造成伤害。非火系伤害命中冰冻目标时，伤害被完全免疫。

---

### 2. Buff 系统扩展

#### 2.1 Buff 架构设计（配置化）

**设计变更**：采用 **BuffConfig + BuffBehavior 配置化驱动** 架构，无需为每种 Buff 创建独立类。

- `BuffConfig`（ScriptableObject）：通过字段定义 Buff 属性（持续时间、CanAct、IsUnique、EffectType、TriggerTiming 等）
- `BuffBehavior`：统一处理所有 Buff 的钩子逻辑
- `Buff`：运行时实例，持有 Config 和 Behavior

Buff 基类已新增以下扩展点：
- `OnBeforeAttacked`：被攻击前触发，可修改伤害值和暴击判定
- `OnDamageTaken`：受到伤害后触发，可检查伤害类型并作出反应
- `CanAct`：控制单位是否能行动（默认 true）

#### 2.2 MarkBuff（猎人标记）

**配置字段**：
- `BuffName` = "Mark"
- `DefaultDuration` = `int.MaxValue`（无限持续）
- `CanAct` = true
- `IsUnique` = true（同一单位不可重复获得）
- `EffectType` = `Marked`
- `TriggerTiming` = `BeforeAttacked`

**效果**：被标记敌人受到攻击时，暴击率强制为 100%。

**实现**：`BuffBehavior.OnBeforeAttacked` 中，当 TriggerTiming 为 `BeforeAttacked` 时，设置 `isCritical = true`。

**注意**：当前 `IsUnique` 仅限制**同一目标**不能重复获得 Mark Buff，跨目标的"单体唯一"（猎人同时只能标记一个敌人）需额外实现。

#### 2.3 FrozenBuff（冰冻）

**配置字段**：
- `BuffName` = "Frozen"
- `DefaultDuration` = 2（配置值）
- `CanAct` = false（无法行动）
- `IsUnique` = false
- `EffectType` = `Frozen`
- `TriggerTiming` = `None`

**效果**：角色无法行动、期间免疫非火系伤害，被火系伤害解除。

**规则**：
- 固定 N 回合（N 为配置值，通过 `ApplyBuffEffect._duration` 传入）
- 冰冻期间 `CanAct = false`
- 受到火系伤害时自动解除冰冻并正常承受伤害
- N 回合后自然消失

#### 2.4 CounterBuff（反击）

**配置字段**：
- `BuffName` = "Counter"
- `DefaultDuration` = 1（持续到下回合）
- `CanAct` = true
- `IsUnique` = false
- `EffectType` = `None`
- `TriggerTiming` = `DamageTaken`

**效果**：持续到下回合，期间受到近战攻击时自动反击。

**实现**：`BuffBehavior.OnDamageTaken` 中，当 TriggerTiming 为 `DamageTaken` 时：
- 检查攻击者是否在近战范围内（距离 ≤ 1）
- 若在近战范围，执行一次完整的近战攻击反击

### 3. CombatComponent 修改

#### 3.1 统一伤害应用方法

`ApplyDamage` 静态方法已整合以下逻辑：
- **破冰检查**：若目标有 Frozen Buff 且伤害为 Fire 元素，则移除 Frozen Buff；若为非 Fire 元素，则免疫伤害
- **暴击判定**：基于攻击者 Luck 属性计算暴击率
- **Buff 钩子**：触发目标 `OnBeforeAttacked`（如 Mark 强制暴击）和 `OnDamageTaken`（如 Counter 反击）
- **防御计算**：应用目标防御减伤

**注意**：`CalculateBaseDamageBeforeCrit` 保持现有逻辑，按 `isRangedDamage` 使用力量（近战）或敏捷（远程）加成，**不新增智力加成**。

#### 3.2 MarkBuff 强制暴击

`ApplyDamage` 中，在暴击判定后、伤害计算前，调用 `target.BuffComponent.OnBeforeAttacked()`：
- 若目标有 Mark Buff（TriggerTiming = BeforeAttacked），则 `isCritical` 被强制设为 true
- 正常计算暴击伤害（伤害 × 2）

---

### 4. 回合系统修改

#### 4.1 Unit 新增 CanAct 属性

`Unit` 和 `IUnit` 已新增 `CanAct` 属性，
`BuffComponent` 的 `CanAct` 通过聚合查询所有 Buff 的 `CanAct` 状态得出（任一 Buff 的 `CanAct = false` 则整体为 false）。

#### 4.2 自动跳过冰冻单位

在 `UnitSpeedTurnResolver.ResolveNextUnit` 中：
- 检查当前行动单位的 `CanAct` 状态
- 若 `CanAct = false`，将单位重新入队并跳过该回合
- 通过 `skipCount` 计数器防止无限循环（所有单位都无法行动的极端情况）

---

### 5. ApplyBuffEffect 实现

`ApplyBuffEffect` 已实现：

**配置字段**：
- `_buffConfig`：`BuffConfig` 引用（ScriptableObject）
- `_duration`：持续回合数（覆盖 BuffConfig 的默认值）

**执行逻辑**：
- 遍历所有目标单位
- 为每个目标创建 `Buff` 实例：`new Buff(_buffConfig, caster, _duration)`
- 通过 `target.AddBuff(buff)` 施加
- `BuffComponent.AddBuff` 会自动处理 `IsUnique` 检查（若 Config.IsUnique = true，且目标已有同 Config 的 Buff，则跳过）

## 验收标准

1. **破冰测试**：法师用火球术（Fire AOE）攻击冰冻敌人 → 冰冻解除，正常造成伤害，范围内其他敌人也受伤害
2. **冰冻测试**：敌人被冰冻术命中后 → 跳过 2 个回合，期间免疫非火系伤害
3. **Mark 测试**：猎人标记敌人后 → 所有对该敌人的攻击强制暴击
4. **职业技能测试**：
   - 野蛮人上勾拳 → 近战物理伤害，击飞并击退 3 格
   - 法师火球术 → AOE Fire 伤害
   - 猎人猛烈射击 → 高伤害，50% 命中率惩罚，更远射程
5. **反击测试**：野蛮人使用反击后 → 持续到下回合，期间受到近战攻击自动反击

## 风险与注意事项

1. **Buff 唯一性**：`BuffConfig.IsUnique` 仅限制同一目标重复获得同类型 Buff，跨目标的"猎人同时只能标记一个敌人"需额外在 Ability/Effect 层实现限制逻辑
2. **冰冻单位跳过回合**：`UnitSpeedTurnResolver` 已加入 `skipCount` 防无限循环保护
3. **AI 适配**：新增 Buff 后，AI 行为树可能需要更新（如 AI 优先攻击被标记的敌人）
4. **上勾拳击退**：`KnockbackEffect` 会沿击退方向寻找最远可行走格子作为落点，若路径被阻挡则提前停止；未实现碰撞额外伤害或眩晕
5. **反击范围**：`BuffBehavior.OnDamageTaken` 中已限制仅当攻击者在近战范围（距离 ≤ 1）时才反击
6. **猛烈射击命中率**：50% 命中率惩罚（`_accuracyPenalty = 0.5f`）叠加目标闪避率，实际命中率可能较低，需平衡基础伤害值
