## 核心原则

- **不添加职业资源系统**（无怒气/充能/标记层数）
- **差异体现在**：技能效果设计 + 主属性伤害计算
- **野蛮人**：主属性力量（近战伤害已有力量加成 ✅）
- **猎人**：主属性敏捷（远程伤害已有敏捷加成 ✅）

### 2. Buff 系统扩展

#### 2.1 Buff 基类扩展（`Buff.cs`）

新增虚方法：

```csharp
public virtual void OnBeforeAttacked(IUnit attacker, ref float damage, ref bool isCritical) { }
public virtual void OnDamageTaken(IUnit attacker, float damage, DamageType damageType) { }
public virtual bool CanAct => true;
```

#### 2.2 MarkBuff

**效果**：被标记敌人受到攻击时，暴击率强制为 100%。

**规则**：
- 无限持续时间（`RemainingTurns = int.MaxValue`）
- 单体唯一：一个猎人同时只能标记一个敌人
- **使用过一次标记后，除非该标记敌人死亡，否则不能再使用标记技能**
- 敌人死亡时自动移除

**实现要点**：
- 新增 `OnBeforeAttacked` 钩子，攻击者检查目标是否有 MarkBuff
- 若有，则设置 `isCritical = true`
- 猎人单位需要追踪当前标记的目标（用于判断能否再次使用标记技能）

#### 2.3 FrozenBuff

**效果**：角色无法行动、无法被伤害，被火系伤害解除。

**规则**：
- 固定 N 回合（N 为配置值，通过 `AbilityConfig` 传入）
- `CanAct = false`
- `OnDamageTaken` 中检查 `damageType == Fire`，若是则移除自身并允许伤害正常生效
- N 回合后自然消失

### 3. CombatComponent 修改

#### 3.1 法术伤害计算

在 `CalculateBaseDamageBeforeCrit` 中新增智力分支：

```csharp
private static float GetAttributeScalingBonus(IUnit unitReference, DamageType damageType, bool isRangedDamage)
{
    switch (damageType)
    {
        case DamageType.Fire:
        case DamageType.Ice:
            return (unitReference.Intelligence - NeutralAttributeValue); // 每点智力 +1 伤害
        case DamageType.Physical:
        default:
            return isRangedDamage 
                ? ((unitReference.Agility - NeutralAttributeValue) / 2f)
                : (unitReference.Strength - NeutralAttributeValue);
    }
}
```

#### 3.2 MarkBuff 强制暴击

在 `CalculateDamageDealt` 中，计算暴击前检查目标是否有 MarkBuff：

```csharp
public float CalculateDamageDealt(IUnit defender, ICell defenderCell, ICell aggressorCell, bool isRangedDamage, DamageType damageType)
{
    var damage = CalculateBaseDamageBeforeCrit(_unitReference, damageType, isRangedDamage);
    
    // MarkBuff 强制暴击
    bool forceCrit = defender.BuffComponent.HasBuff<MarkBuff>();
    bool isCritical = forceCrit || IsCriticalHit();
    
    return isCritical ? GetCriticalDamage(damage) : damage;
}
```

### 4. 回合系统修改

#### 4.1 Unit.cs 新增 CanAct 属性

```csharp
public bool CanAct => _buffComponent?.ActiveBuffs.All(b => b.CanAct) ?? true;
```

#### 4.2 自动跳过冰冻单位

在 `UnitSpeedTurnResolver` 或回合开始逻辑中：

```csharp
public TurnContext ResolveTurn(GridController gridController)
{
    CleanDeadUnits(gridController);
    
    // 如果当前单位无法行动，自动跳过
    while (_unitQueue.Count > 0 && !_unitQueue.Peek().CanAct)
    {
        var skippedUnit = _unitQueue.Dequeue();
        _unitQueue.Enqueue(skippedUnit);
        // 可选：触发跳过回合的视觉反馈
    }
    
    return ResolveNextUnit(gridController);
}
```

**或者在 `GridController.MakeTurnTransition` 中处理**：

```csharp
foreach (var unit in TurnContext.PlayableUnits())
{
    unit.OnTurnStart(this);
    
    // 如果单位无法行动，自动结束回合
    if (!unit.CanAct)
    {
        unit.EndTurn(this);
        continue;
    }
    
    foreach (var ability in unit.GetBaseAbilities())
        ability.OnTurnStart(this);
}
```

```csharp
public class ApplyBuffEffect : AbilityEffect
{
    [SerializeField] private string _buffType; // "Mark", "Frozen", "Ignite" 等
    [SerializeField] private int _duration = 3; // FrozenBuff 使用此值
    
    public override Task Execute(IUnit caster, IEnumerable<IUnit> targets, IGridController gridController)
    {
        foreach (var target in targets)
        {
            switch (_buffType)
            {
                case "Mark":
                    // 检查猎人是否已有活跃标记
                    if (caster is IMarkUser markUser && markUser.CurrentMarkedTarget != null)
                    {
                        // 不能重复标记，跳过或报错
                        continue;
                    }
                    var markBuff = new MarkBuff(caster);
                    target.AddBuff(markBuff);
                    if (caster is IMarkUser mu) mu.CurrentMarkedTarget = target;
                    break;
                    
                case "Frozen":
                    target.AddBuff(new FrozenBuff(caster, _duration));
                    break;
                    
                default:
                    // 其他 Buff 类型
                    break;
            }
        }
        return Task.CompletedTask;
    }
}
```

## 验收标准

1. **破冰测试**：法师用火球术（Fire）攻击冰冻敌人 → 冰冻解除，正常造成伤害
2. **冰冻测试**：敌人被冰冻术命中后 → 跳过 N 个回合，期间无法被任何伤害（包括非火系）
3. **Mark 测试**：猎人标记敌人后 → 所有对该敌人的攻击强制暴击；标记敌人死亡前不能再标记其他敌人
4. **属性加成测试**：
   - 野蛮人重击 → 伤害 = AttackFactor + (Strength - 5) × 1.5
   - 法师火球术 → 伤害 = AttackFactor + (Intelligence - 5)
   - 猎人穿心箭 → 伤害 = AttackFactor + (Agility - 5) / 2 × 1.5

## 风险与注意事项

1. **Buff 唯一性**：MarkBuff 的单体唯一性需要 Hunter 单位追踪当前标记目标，建议新增 `IMarkUser` 接口或在 `Unit` 上添加字段
2. **伤害类型兼容性**：现有技能默认 `Physical`，新增 `Fire`/`Ice` 不会影响现有战斗
3. **冰冻单位跳过回合**：需要确保跳过逻辑不会导致无限循环（如果所有单位都冰冻）
4. **AI 适配**：新增 Buff 后，AI 行为树可能需要更新（如 AI 优先攻击被标记的敌人）
