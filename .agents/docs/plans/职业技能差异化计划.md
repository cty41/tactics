# Task2: 职业技能差异化（修订版）

## 核心原则

- **不添加职业资源系统**（无怒气/充能/标记层数）
- **差异体现在**：技能效果设计 + 主属性伤害计算
- **野蛮人**：主属性力量（近战伤害已有力量加成）
- **猎人**：主属性敏捷（远程伤害已有敏捷加成）
- **法师**：主属性智力（新增法术伤害基于智力）

---

## 开发内容

### 1. DamageType 系统

在 `AbilityConfig` 中新增 `DamageType` 枚举，包含以下类型：
- `Physical`：物理伤害
- `Fire`：火焰伤害
- `Ice`：冰霜伤害

**属性加成规则**：

| DamageType | 属性加成 |
|-----------|----------|
| `Physical` + 近战 | 力量 |
| `Physical` + 远程 | 敏捷 |
| `Fire` / `Ice` | 智力 |

**破冰机制**：火系伤害命中冰冻目标时，自动移除 `FrozenBuff`，然后正常造成伤害。

---

### 2. Buff 系统扩展

#### 2.1 Buff 基类扩展

Buff 基类需新增以下扩展点：
- `OnBeforeAttacked`：被攻击前触发，可修改伤害值和暴击判定
- `OnDamageTaken`：受到伤害后触发，可检查伤害类型并作出反应
- `CanAct`：控制单位是否能行动（默认 true）

#### 2.2 MarkBuff（猎人标记）

**效果**：被标记敌人受到攻击时，暴击率强制为 100%。

**规则**：
- 无限持续时间
- 单体唯一：一个猎人同时只能标记一个敌人
- 使用过一次标记后，除非该标记敌人死亡，否则不能再使用标记技能
- 敌人死亡时自动移除标记

**实现要点**：
- 攻击者检查目标是否有 MarkBuff，若有则设置暴击
- 猎人单位需要追踪当前标记的目标（用于判断能否再次使用标记技能）

#### 2.3 FrozenBuff（冰冻）

**效果**：角色无法行动、期间无法被非火系伤害，被火系伤害解除。

**规则**：
- 固定 N 回合（N 为配置值，通过 `AbilityConfig` 传入）
- 冰冻期间 `CanAct = false`
- 受到火系伤害时自动解除冰冻并正常承受伤害
- N 回合后自然消失

---

### 3. CombatComponent 修改

#### 3.1 法术伤害计算

`CalculateBaseDamageBeforeCrit` 中新增智力分支：
- `Fire`/`Ice` 类型伤害使用智力属性加成
- `Physical` 类型保持原有力量/敏捷加成逻辑

#### 3.2 MarkBuff 强制暴击

`CalculateDamageDealt` 中，计算暴击前检查目标是否有 MarkBuff：
- 若有 MarkBuff，则暴击判定强制为 true
- 正常计算暴击伤害

---

### 4. 回合系统修改

#### 4.1 Unit 新增 CanAct 属性

`Unit` 或 `IUnit` 新增 `CanAct` 属性，通过查询 `BuffComponent` 中所有 Buff 的 `CanAct` 状态聚合得出。

#### 4.2 自动跳过冰冻单位

在回合解析器或回合开始逻辑中：
- 检查当前行动单位的 `CanAct` 状态
- 若 `CanAct = false`，自动跳过该单位的回合
- 需确保跳过逻辑不会导致无限循环（所有单位都无法行动的极端情况）

**可选实现位置**：
- `UnitSpeedTurnResolver.ResolveTurn` 中排队时过滤
- `GridController.MakeTurnTransition` 中逐个检查并跳过

---

### 5. ApplyBuffEffect 完成

当前 `ApplyBuffEffect` 为 TODO 状态，需要实现以下功能：

**配置字段**：
- `_buffType`：Buff 类型标识字符串（如 "Mark"、"Frozen"）
- `_duration`：持续回合数（FrozenBuff 使用此值）

**执行逻辑**：
- 根据 `_buffType` 创建对应 Buff 实例
- MarkBuff：检查猎人是否已有活跃标记，若有则跳过；否则施加标记并记录目标
- FrozenBuff：直接施加，传入配置的持续回合数

## 验收标准

1. **破冰测试**：法师用火球术（Fire AOE）攻击冰冻敌人 → 冰冻解除，正常造成伤害，范围内其他敌人也受伤害
2. **冰冻测试**：敌人被冰冻术命中后 → 跳过 N 个回合，期间无法被任何伤害（包括非火系）
3. **Mark 测试**：猎人标记敌人后 → 所有对该敌人的攻击强制暴击；标记敌人死亡前不能再标记其他敌人
4. **属性加成测试**：
   - 野蛮人上勾拳 → 近战 Physical 伤害，击飞并击退 3 格
   - 法师火球术 → AOE Fire 伤害 = AttackFactor + (Intelligence - 5)
   - 猎人猛烈射击 → 高伤害，70% Miss，50% 暴击，更远射程
5. **反击测试**：野蛮人使用反击后 → 持续到下回合，期间受到攻击自动反击

## 风险与注意事项

1. **Buff 唯一性**：MarkBuff 的单体唯一性需要 Hunter 单位追踪当前标记目标，建议新增 `IMarkUser` 接口或在 `Unit` 上添加字段
2. **伤害类型兼容性**：现有技能默认 `Physical`，新增 `Fire`/`Ice` 不会影响现有战斗
3. **冰冻单位跳过回合**：需要确保跳过逻辑不会导致无限循环（如果所有单位都冰冻）
4. **AI 适配**：新增 Buff 后，AI 行为树可能需要更新（如 AI 优先攻击被标记的敌人）
5. **上勾拳击退**：需要处理击退目标位置已有单位或障碍物的情况（可能造成额外伤害或眩晕）
6. **反击 Buff**：需要定义反击的触发条件（是否消耗行动点、是否有次数限制）
7. **猛烈射击 Miss 率**：70% Miss 率较高，需要平衡伤害值以确保技能有使用价值
