核心原则：进入节点时设置 `Tactics_EventInProgress` 标记，事件完成后才提交路径并清除标记，不保存预战斗快照。

| 文件 | 改动 |
|------|------|
| `RoguelikeEventReentryManager.cs` | **新建** — 静态工具类，封装 `MarkEventInProgress()`、`ClearEventInProgress()`、`IsEventInProgress()` 三个方法 |
| `RoguelikeBattleReturnHandler.cs` | `ApplyRoguelikePathAfterBattle()` 从 `OnBattleEnded` 移到 `onComplete` 回调；`onComplete` 中清除事件标记 |
| `RoguelikeMapUIController.cs` | `EnterBattleNode()` 中 `MarkEventInProgress("Battle", p)`；`EnterStubNode()` 中根据 nodeType 映射事件类型并标记；`CoUnlockAfterStub()` 中清除标记；`LoadOrGenerateMap()` 末尾增加中断检测 |

##### 数据流

```
正常流程:
点击 Battle 节点 → EnterBattleNode() → MarkEventInProgress("Battle") → StartBattle
→ 战斗胜利 → OnBattleEnded（不提交路径）→ 结算UI → 升级 → 属性加点 → 技能选择
→ onComplete回调 → Save状态 → ApplyRoguelikePathAfterBattle（提交路径）
→ ClearEventInProgress → EndBattleAsync → 返回地图

中断流程:
点击 Battle 节点 → ... → 结算中游戏退出
→ onComplete 未触发，标记残留，路径未前进
→ 重进游戏 → LoadOrGenerateMap 检测到 IsEventInProgress
→ 清除标记 → 地图节点仍可选 → 玩家重新点击
```

##### 所有事件节点共用统一标记

| 节点类型 | 事件类型 | 标记位置 | 清除位置 |
|---------|---------|---------|---------|
| Battle (Minor/Elite/Boss) | "Battle" | `EnterBattleNode` | `onComplete` 回调 |
| RestSite | "Rest" | `EnterStubNode` | `CoUnlockAfterStub` |
| Store | "Store" | `EnterStubNode` | `CoUnlockAfterStub` |
| Treasure | "Treasure" | `EnterStubNode` | `CoUnlockAfterStub` |
| Mystery | "Mystery" | `EnterStubNode` | `CoUnlockAfterStub` |
