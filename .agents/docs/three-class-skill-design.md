# 三职业首批技能设计

## 文档定位

本文只描述当前首批可运行技能。技能目录资产、`SkillGraphAsset` 与自动化测试是实现事实源；本文用于解释职业结构和必须长期保留的设计约束。

## 通用规则

- 固定职业为法师、死灵法师、亚马逊。
- 每个职业当前有 3 个基础技能和 3 个对应高级技能，共 18 个技能。
- 基础技能：主属性达到 5 可学习，最高 Lv3，无前置技能。
- 高级技能：对应属性达到 7 且已学习指定基础技能，最高 Lv2。
- 每名角色最多装配 3 个主动技能和 3 个被动技能。
- 首批技能的具体数值、节点和目标规则由技能目录与 SkillGraph 资产定义，不在本文重复维护。

## 关键行为约束

### 诅咒分支

- 基础技能是“伤害加深诅咒”，不存在“虚弱诅咒”。
- Lv2 高级技能“恐惧诅咒”由玩家指定一个地块，影响该地块及其上、下、左、右相邻格，共 5 格十字范围。
- 范围、持续时间和具体效果以 SkillGraph 与对应测试为准。

### 长矛闭环

- 长矛结算完所有命中后，掉落在最后命中单位附近的可用空格。
- 长矛不存在“嵌入敌人”的中间状态。
- 若附近格不可用，实际落点由运行时的可用格搜索规则决定。
- 学会任一投掷系技能后会自动获得额外技能“拾取长矛”；它不参与升级候选，也不在地图只读技能区显示。
- “拾取长矛”要求亚马逊位于落地长矛八方向相邻格，消耗为 0；毒矛在长矛未回收时保持可点击置灰提示。
- 未持矛不会禁用移动。进入移动选择时，长矛格显示橙色，八方向可站立拾取位置显示绿色并覆盖普通青蓝移动高亮；绿色只提供位置引导，不扩大本回合移动范围。
- 高级技能“召唤长矛”沿用历史稳定 ID `amazon.recover_spear`，只有 Lv1/Lv2，并带投掷系标签。它把同一支落地长矛召回到选定空格；Lv2 额外对亚马逊正交相邻四格敌人造成电系魔法伤害。

## 边界

职业精通、通用被动、更多技能分支和长期平衡数值尚未进入当前实现范围；这些候选项统一记录在 [项目已知缺口](project-known-gaps.md)，不得写成已经存在的系统。
