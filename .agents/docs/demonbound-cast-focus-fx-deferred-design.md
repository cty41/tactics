# Demonbound Cast Focus FX（延期设计）

## 范围与边界

本设计描述未来 Cast 聚能表现，当前不实现代码、Godot Resource、场景、运行时纹理绑定或公共 API。Cast Sprite 始终保持无光效；FX 是独立、可按技能替换的程序化表现。

## 挂点合同

- 未来角色表现数据为 Cast DR 与 Cast UL 各保存一个 `focusAnchor`，坐标以对应 `256×256` 正式母图的像素坐标记录，锚在剑尖。
- 运行时按当前姿态和朝向将该局部坐标转换到角色父坐标；翻转时只按 Sprite 的既定翻转/朝向规则镜像 x，不从 Alpha 边界、特效边缘或剑身轮廓推导挂点。
- DR/UL 分别显式存储，不能假设一张图的坐标可镜像代替另一张图；后续母图重校准时必须连同挂点重新审核。

## 时序与 Profile 职责

| 阶段 | FX 行为 | 责任 |
|---|---|---|
| `charge` | 剑尖挂点出现克制的聚焦点/细环并渐强。 | 通用 Cast Focus 控制器处理挂点、时钟和基础缩放；Skill Profile 指定颜色、形状与强度。 |
| `release` | 在同一挂点触发短促闪现，并交给技能自己的投射物或命中 FX。 | Skill Profile 决定 release 资产、目标方向与是否生成独立投射物。 |
| `recover` | 聚焦点快速衰减、清理，不残留在 Sprite。 | 通用控制器保证取消、死亡和动作切换时回收。 |

基础 Cast 不承载 Bane 的表现；Bane 仍是 `Melee` 呈现，使用正式 Melee Sprite 与独立两格紫色半月斩。未来实现时需先建立独立计划并明确 Profile 数据模型、生命周期、遮挡层和性能预算。
