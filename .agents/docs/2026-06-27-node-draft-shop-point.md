## 一句话定义

商店点不是“顺手买点东西的消费点”，而是一个把当前 run 中已经积累的金币，兑现成现实能力与路线成立性支点的资源转化节点。

最接近的 Mew 参考，不是单个固定房间，而是固定 `shop` 节点与事件直开商店的双层结构。

关键启发不是“商店里卖什么”，而是：

- 金币必须及时转成当前 run 的现实能力
- 商店点要能让原本差一点不成立的路线或配置重新变得值得比较
- 商店可以卖泛用装备和消耗品，但不能只靠“泛用舒服货”来成立

## 正式节点定义

### 节点名

商店点

### 决策职责

让玩家在“把已有金币立刻转成当前稳定性/构筑价值”与“继续持币等待更好的转化窗口”之间做判断。

这意味着商店点不是单纯的购物入口，而是在逼玩家回答：

- 这笔钱现在值不值得转成当前真的有用的能力

### 首要服务对象

当前这支固定三人小队已经积累了一定金币，但这些金币还没有被有效转成当前 run 的稳定性或构筑优势。

商店点主要服务的不是：

- 快崩的小队
- 任何手里有一点钱的小队

而是：

- **已经拿到资源，但这些资源仍停留在潜在价值状态的小队**

### 默认劝玩家做什么

先把一部分金币转成当前 run 立刻能生效的稳定性或构筑价值。

这里的重点不是“先把钱花掉”，而是：

- 现在就把一部分潜在资源兑现成现实能力

### 默认劝退哪种选择

- 一味持币观望，迟迟不把金币转成当前能力

### 对抗的玩家冲动

“先把钱捏着，等以后更值的机会再说。”

这类冲动的问题不在于等待本身，而在于：

- 该转成当前能力的资源被长期搁置
- 队伍本可成立的路线与配置被无谓延后

### 顺着冲动走下去的代价

如果玩家持续顺着“先捏着钱再说”的冲动往前走，最主要的代价不是“少买了一点东西”，而是：

- 金币长期停留在潜在价值状态
- 当前 run 的稳定性和构筑机会被持续延误
- 原本可以提前成立的解法集合迟迟打不开

更具体地说：

- 某条原本差一点不敢接的路线，一直停留在“理论上不错，但现在还不成立”的状态

### 对下一轮解法集合的作用

有条件扩宽。

商店点不像补给点那样负责恢复已丢失的解法，也不像战斗点那样用风险换成长跃迁。它更像：

- 把已有金币转成一个现实能力支点
- 让原本边缘可行的路线或配置第一次成立

因此，商店点的作用不是保证任何购买都成立，而是：

- **当转化正确发生时，把原本“差一点”的路线推到值得重新比较的层级**

## 资源与结果作用范围

### 主收益

商店点的主收益是资源兑现相关结果：

- 把金币转成稳定性支点
- 把金币转成更合理的装备结构
- 把金币转成更清晰的资源结构
- 把金币转成某条路线成立所缺的关键条件

### 次级收益

商店里可以卖：

- 角色泛用装备
- 角色泛用消耗品
- 定向构筑物
- 稳定性资源

但这些泛用货只能作为商店点的一部分价值，不能成为它成立性的唯一来源。

### 最低非泛用职责

商店点至少必须提供一种非泛用型价值：

- **能让原本差一点不成立的路线或配置，重新变得值得比较**

## 风险态定义

商店点默认要把玩家从：

- “我先把钱捏着，等以后更值的机会再说”

推向：

- “我现在已经有一笔资源，它应该被转成一个足以支撑下一步选择的现实能力”

这里的“现实能力”首先不该理解成“更舒服一点”，而应理解成：

- 一条原本差一点不敢接的路线，现在第一次说得通了

## 成功标准（节点级）

### 最低成功线

商店点的最小成功，不应定义为“买到了东西”，而应定义为：

- 买完之后，至少有一种原本边缘的路线或配置选择，变得值得重新比较

### 最先打开出来的边缘选择

商店点最先应让以下类型的边缘选择重新变得值得比较：

- 原本因为稳定性不足而不敢走的路线

也就是说，商店点最典型的成功，不是“更强了”，而是：

- 原本差一点不成立的路线，现在因为一个稳定支点而成立了

### 最理想成功像

商店点最理想的成功，不是让玩家觉得“买得很值”或“花钱很舒服”，而是让玩家产生：

- “这条路以前不是不值，而是我当时还没把资源兑现出来；现在终于兑现出来了。”

### 现实能力的第一表现

商店点兑现出的现实能力，最先应表现成：

- 当前小队第一次具备承接某条原本差一点不成立路线的稳定支点

这个支点最先不该被误读成：

- 只是买到了一个泛用更强的东西

因为商店里可以有泛用货，但商店点不能只靠泛用舒服货成立。

## 失败标准（节点级）

### 典型失败像

玩家逛完商店、买到了东西，但下一轮路线判断几乎不变。

这说明：

- 金币被花掉了
- 但没有真正兑现成当前 run 的现实能力

### 第一层失败解释

商店点没有把潜在资源兑现成现实能力，只完成了表面消费。

常见表现：

- 买完只是更舒服一点
- 队伍没有因此重新获得某条原本不成立路线的资格
- 玩家只是少了一笔钱、多了一件货，但后续选择没有变化

### 不该出现的另一种失败

商店点不应被理解成“一个把钱花掉、顺便拿点强化的地方”。

如果商店点只能提供这种体验，它就还没有进入地图决策层。

## 试玩观察口径（节点级）

试玩时，优先观察以下问题：

1. 玩家进入商店点前，是否明确把它视为一次“把潜在金币转成现实能力”的机会？
2. 玩家买完之后，是否真的多出至少一种新的、说得通的路线或配置选择？
3. 玩家是否会因为这次购买，重新比较那条原本差一点不敢接的路线？
4. 玩家是否把商店点误判成“有钱就顺手逛一下”的消费点？如果会，说明节点职责写歪了。
5. 玩家是否能明确说出：这次购买让哪条原本不成立的路线或配置第一次成立了？

## 与其他节点的边界

### 与补给点的边界

- 补给点修 `HP / MP / 死亡风险`
- 商店点把金币兑现成稳定性、装备支点或资源结构

### 与战斗点的边界

- 战斗点通过风险投入换成长跃迁机会
- 商店点通过已有金币兑现现实能力

### 与成长点的边界

若未来保留少量特殊非战斗成长点，则边界应这样拉：

- 成长点：提供低频、定向、明确的成长机会
- 商店点：不直接给成长，而是把已有经济转成当前成立路线所缺的支点
