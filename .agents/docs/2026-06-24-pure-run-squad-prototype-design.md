## 一句话定位

这是一个以 `固定三人小队` 为核心单位、以 `FTL 式自由星图` 为推进结构、以 `职业分支 + 技能 + 装备 + 消耗品` 为 run 内成长源的战棋构筑原型。

它不验证带出收益，不验证局外成长，而是验证：玩家是否愿意在一局结束后，立刻再开一局尝试另一种三人协同构筑。

## 核心设计决策

### 1. 不把成长带到局外

- run 结束后，主成长清空
- 不存在装备带出
- 不存在撤离收益
- 不存在跨局积累的主成长线

局外层最多只保留轻量解锁空间，但不应成为原型阶段的重点。

### 2. 保留 FTL 式自由星图

- 地图仍然采用可探索的星图结构
- 重点保留路径选择、信息不完全和推进顺序判断
- 但星图的价值从“如何把收益带出去”改成“如何为本局三人小队找到更合适的成长路径”

这意味着它不是线性爬塔，也不是纯菜单跳点，而是保留探索感的 run 内构筑地图。

### 3. 保留固定三人小队

- 每个 run 开始时确定 3 名角色
- 单个 run 内不换人、不招募替补
- 整个 run 的构筑核心是三人分工、技能协同、装备分配和资源调度

这条决策非常关键。它把产品从“单角色构筑游戏”拉向了“战术小队构筑游戏”。

## 成长结构

本原型采用三层成长源，分别承担不同职责。

### 职业分支：定义成长骨架

- 每个角色都有明确职业身份
- 每个职业至少有 2-3 条可辨识的分支方向
- 职业分支决定该角色更适合承担什么职责

职业分支的作用不是单纯加数值，而是回答：

1. 这个角色在小队里负责什么
2. 这个职业自己玩起来爽在哪
3. 他的技能池偏向什么
4. 他与队友能形成哪些特殊组合乐趣
5. 装备优先级会偏向什么

### 技能：定义战斗联动

- 技能是角色在战斗中的主要表达层
- 技能成长应改变操作顺序、目标选择、站位偏好或队友配合
- 技能不是独立系统，而必须和职业分支与装备形成联动

技能的设计目标不是“角色各玩各的”，而是让玩家产生类似这样的思考：

- 先由 A 上 debuff，再让 B 收割
- C 负责保护或补位，让 A/B 能继续滚起来

### 装备槽：定义角色配置

- 不使用“遗物”模型
- 使用传统装备槽表达成长
- 装备应明显影响角色职责，而不是只替换更高数字

装备的意义在于：

1. 让掉落具有“给谁穿”的决策价值
2. 让同一个职业分支在不同 run 中产生不同构筑手感
3. 让小队内部出现资源分配冲突

### 消耗品槽：定义资源调度

- 消耗品是 run 内资源管理的重要组成部分
- 它既服务战斗，也服务星图推进
- 消耗品不应只是回血瓶，还应承担临时补强、解局和容错的作用

消耗品的存在，是为了让玩家在“继续推进”和“保守保命”之间做更细的判断。

## 首个真实 Run 的预设三职业规格 v1

首个真实 run 不做开局选人，而是使用 `固定预设三职业`。目的不是提前锁死最终职业阵容，而是先用一套受控实验组验证三件事：

1. 职业本身是否各自成立且好玩
2. 三人之间是否存在清晰但不僵硬的职责结构
3. run 内资源是否会根据敌人、掉落和当前压力在三人之间动态偏移

### 职业 1：死灵法师

#### 职业爽点

- 操控亡灵在前线顶住压力
- 通过诅咒削弱敌人，用较低的正面暴露去遥控战斗
- 具备明显的“一人成军”倾向

#### 队伍职责

- 默认的前场制造者
- 通过召唤物承担主要承压骨架
- 通过诅咒制造削弱、路径干扰和阵型约束

#### 组合特征

- 对他人依赖最低，是三职业中最能独立运转的角色
- 其真正价值不在于独自终结战斗，而在于为队友创造更适合输出和几何兑现的局面

#### 关键限制

- 召唤物数量不是主要问题，真正限制是 `召唤物质量有限`
- 召唤物足以构成前场骨架，但不足以单独稳定解决前线压力
- 这保证死灵法师不会强到把另外两个职业变成附属挂件

### 职业 2：法师

#### 职业爽点

- 范围爆发
- 火系魔法负责高伤害 AOE 清场
- 冰系魔法负责中等伤害 AOE 并施加寒冷 buff，形成持续减速与控场

#### 队伍职责

- 队伍中的 `清场核心`
- 同时具备控场价值，但本体 build 的重点是 `火法清场 / 冰法控场` 的模式切换

#### 组合特征

- 与亚马逊不是上下位关系，而是 `双核并存`
- 法师负责解决密集敌群、散怪清理和行动效率压制
- 当敌人不适合穿线时，法师应成为更自然的场面接管者

#### 关键限制

- `脆，怕贴脸`
- 一旦被近身，法师的清场与控场价值会迅速下降
- 因此法师需要死灵的前场骨架与全队的站位保护来稳定兑现价值

### 职业 3：亚马逊女战士

#### 职业身份

- `近战几何型主核，远程投掷型副核`
- 武器设定为 `持盾 + 长矛/标枪`
- 战斗气质是 `敏捷格挡型中前场`，不是传统重装前排

#### 职业爽点

- 最核心的手感不是捡回标枪，也不是单纯高伤，而是 `站在正确位置，让近战十字穿透攻击吃到整条有效线`
- 近战模式才是她最主要的高光兑现方式
- 投掷模式提供更高单体伤害，但不承担主几何高光

#### 第一主决策

- `这一枪现在该近战打，还是投掷出去`

这个决策不是风格切换，而是价值切换：

- 近战：主打几何兑现、穿线、多段打击与局部控位
- 投掷：主打单体高伤、远端关键目标处理和安全输出

#### 近战价值

- 近战武器具备 `三格十字穿透攻击`，这是她最具辨识度的主高光
- 近战技能应围绕 `多段打击 + 穿透覆盖 + 控位辅助` 展开
- 她的代表性回合不是贴身处决一个目标，而是 `用近战吃到整条有效攻击线`

#### 投掷价值

- 投掷只打一个单位，但伤害比近战更高
- 投掷主要用于：
  - 打远端关键目标
  - 在不适合贴身时保持威胁
  - 作为近战几何之外的副核输出模式

#### 回收机制的定位

- 标枪投出后需要回收，这一设定保留
- 但它的定位是 `风味 + 平衡限制`，而不是职业成立根基
- 换言之，去掉“捡枪”的麻烦后，这个职业仍然成立；真正支撑她的，是近战几何和双态切换

#### 关键限制

- 她最怕的不是贴脸，而是 `敌人站得太散`
- 一旦敌人无法形成有效线，她的近战主高光就很难兑现
- 因此她不是任何局面都稳定强，而是一个明显吃阵型条件的主核

#### 主配合对象

- 她最希望配合的不是法师，而是 `死灵法师`
- 原因不是吃 buff，而是死灵法师的召唤物与诅咒更容易把敌人挤成适合穿线的结构

### 三职业之间的结构关系

#### 默认前场结构

- 默认前场承压者是 `召唤物`
- 亚马逊不是传统意义上的主坦，她更像 `借前场打高光的人`
- 法师则明确站在后场，靠空间安全兑现清场价值

#### 主配合链

- `死灵法师 -> 亚马逊` 是首条最明确的主配合链
- 死灵法师负责把敌人限制到更适合穿线的位置
- 亚马逊负责将这种位置优势转化为近战几何收益

#### 双核关系

- `法师` 与 `亚马逊` 是双核并存，不是辅助关系
- 两者的区别不在于谁伤害更高，而在于谁吃的场面条件不同：
  - 法师吃 `范围密度`
  - 亚马逊吃 `线性几何`

#### 团队级天敌

- 这支队伍最怕的不是纯正面硬碰，而是 `远程分散火力队`
- 原因：
  - 召唤物难以有效卡住整片场面
  - 亚马逊难以吃到有效穿线
  - 法师的 AOE 覆盖价值被稀释，且自身又怕持续远程消耗

#### 资源倾斜原则

- 这支队伍没有固定唯一主 C
- run 内资源应根据 `敌人类型 + 掉落结果 + 当前节点压力` 动态偏移
- 资源倾斜逻辑示例：
  - 更适合铺场与阵型限制的战斗：偏死灵法师
  - 更适合穿线兑现、关键单体处理的战斗：偏亚马逊
  - 更适合大范围清场、散怪处理与控场切模式的战斗：偏法师

这条原则是 pure run 重开价值的重要来源之一：同一套三职业，因敌人、地图和掉落不同，可以在不同局里形成不同的主核重心。

## 技能层讨论沉淀 v0

以下内容用于保留当前已经完成的技能层讨论结果。它们代表“首轮实现前已确认的技能方向”，不等同于最终完整职业树。

### 当前方法调整

- 目前已经确认：如果继续逐个技能直接细化到所有实现参数，会出现从下往上的倒置风险。
- 因此当前技能层讨论只保留两类内容：
  1. 已经足够稳定、值得留档的技能定义
  2. 明确列出的 TODO，等待中上层 build 框架确定后再回填

### 法师：首轮技能包（已明确）

法师首轮技能包的目标，不是把完整法术库做完，而是用最少的一组技能验证三件事：

1. 火 / 冰双模式是否成立
2. 法师是否真的是清场核心而非纯炮台
3. 脆、怕贴脸这一弱点是否通过位移技能变成可操作问题，而不是纯处罚

#### 已确定的技能清单

- 基础单体法术：`火球术`
- 基础单体法术：`寒冰箭`
- 高阶 AOE 法术：`陨石术`
- 高阶 AOE 法术：`暴风雪`
- 位移 / 保命技能：`瞬移术`

这 5 个技能在首轮中的职责分工为：

- `火球术` / `寒冰箭`：提供稳定的单体输出与基础模式表达
- `陨石术` / `暴风雪`：提供火法清场与冰法控场的高阶兑现手段
- `瞬移术`：体现法师脆、怕贴脸时的操作空间

#### 火球术（已细化到实现参数）

##### 技能定义

- 目标类型：指定目标发射
- 技能形状：`单体命中 + 小爆炸`
- 爆炸范围：`命中点所在十字 1 格`
- 施法距离：`5 格`
- 视线规则：`需要视线`
- 友伤规则：`不伤友军`

##### Projectile 规则

- 以 `projectile` 形式直线飞行
- `只有敌方单位阻挡`
- 碰到路径上第一个敌方单位即爆炸
- 爆炸位置以实际命中点为准，不保证一定命中原指定目标

##### 效果定义

- 主命中单位：`极高伤害`
- 十字溅射单位：`很低伤害`
- 附加效果：
  - `破冰`
  - `点燃`

##### 资源规则

- 冷却：`无冷却`
- 法力消耗：`低消耗`

##### 功能完成度验收

1. 只能在 `5 格 + 视线内` 合法施放
2. 火球会沿直线飞行，不是瞬发
3. 友军和己方召唤物不会拦截火球
4. 第一个敌方阻挡单位会吃到主命中并触发爆炸
5. 爆炸会正确作用于命中点十字 1 格
6. 不会误伤友军
7. 主命中高伤、溅射低伤结算正确
8. 对冰冻目标能正确破冰
9. 点燃会正确施加到命中的合法敌方单位
10. 技能释放后只扣低法力，不进入冷却
11. 预览与实际命中结果一致

##### 技能定义

- 技能形状：`直线 projectile 单体命中`

- `基础冰魔法`：只负责发放寒冰箭，不强化它
- `高级冰魔法`：降低 `寒冰箭` 的 MP 消耗
- `大师冰魔法`：寒冰箭命中后有概率 `反弹` 至附近 `3 格` 内的 `其他单位`，反弹伤害减半

##### 功能完成度验收

1. 能正确指定目标并发射直线 projectile
2. projectile 会被路径上第一个敌方单位拦下并结算
3. 命中后正确造成单体伤害
4. 命中后正确施加冰冻减速 debuff
5. 技能不会继续穿透命中后续目标
6. 高级冰魔法生效后，寒冰箭 MP 消耗正确降低
7. 大师冰魔法生效后，寒冰箭命中后会按概率检查反弹
8. 反弹目标只在命中点附近 `3 格` 范围内选取
9. 反弹伤害正确按减半结算
10. 预览、飞行表现、命中反馈与实际结算一致

#### 霹雳闪电（已细化到实现参数）

##### 技能定义

- 目标类型：指定单位
- 技能形状：`单体直接命中`
- 施法距离：待后续补数值
- 视线规则：`不受视觉阻挡影响`
- 友伤规则：待后续确认，当前默认不伤友军

##### 命中规则

- 直接对目标单位生效
- 不使用 projectile
- 不存在弹道或飞行过程
- 不受中间单位阻挡

##### 效果定义

- 对目标单位造成伤害
- `基础电魔法`：只负责发放霹雳闪电，不强化它
- `高级电魔法`：为霹雳闪电增加 `小概率眩晕`
- `大师电魔法`：进一步提高 `眩晕概率`

##### 功能完成度验收

1. 能正确指定合法目标并即时生效
2. 技能不生成 projectile，不走飞行过程
3. 中间单位不会阻挡霹雳闪电命中目标
4. 目标单位会正确承受单体伤害
5. 高级电魔法生效后，霹雳闪电会按设定小概率施加眩晕
6. 大师电魔法生效后，眩晕概率会正确提高
7. 非法目标选择会被正确拦截
8. 技能预览、即时命中反馈与实际结算一致

#### 瞬移术（已细化到实现参数）

##### 技能定义

- 目标类型：指定地块
- 技能形状：`瞬时位移`
- 施法范围：`视觉可见范围内` 且在技能允许的最大距离内
- 友伤规则：无

##### 位移规则

- 角色瞬间移动到指定位置
- 不使用 projectile
- 基础形态要求目标地块 `视觉可见`
- 必须在技能允许的位移距离内

##### 与专长阶段的关系

- `高级电魔法`：瞬移术进入技能候选池
- `大师电魔法`：
  - 降低瞬移术魔法消耗
  - 允许瞬移术 `无视视觉可见性`

##### 功能完成度验收

1. 能正确选择合法地块作为位移终点
2. 超出技能距离的地块会被正确拦截
3. 基础形态下，不可见地块无法被选择
4. 位移后角色正确出现在指定位置
5. 位移不生成弹道或飞行过程
6. 大师电魔法生效后，瞬移术法力消耗正确降低
7. 大师电魔法生效后，不可见但合法的终点可被选择
8. 预览、合法落点显示与实际位移结果一致

## 亚马逊分支骨架 v1

### 参考来源（Mew）

亚马逊的三条职业专长线不直接照搬 `Mew` 里的某个职业，而是综合借用近战职业的几类能力表达：

1. `Fighter`
   - `Dash`：冲脸开团、近战位移压迫
   - `Spin`：多段近战、范围命中
   - `ThunderPunch`：单点控制与元素打断
2. `Butcher`
   - `HogRush`：带位移和路径压迫的近战动作
   - `Burp`：击退 / 逼位
   - `Mutilate`：多段或重近战伤害表达

这些参考帮助亚马逊在“近战几何主核、远程投掷副核、敏捷格挡型中前场”的前提下形成三条职业专长线。

### 总规则

- 亚马逊与法师、死灵法师一样，至少拥有 `3 条职业专长线`
- 开局从 3 条基础专长线中随机获得 1 条
- 同时自动获得对应的基础技能
- `基础专长` 只负责发放基础技能并确定分支起点
- `高级专长` 打开功能技能候选
- `大师专长` 打开终局技能候选并强化整条线已有技能

### 分支 1：长矛专长

定位：

- 亚马逊最核心的近战几何主线
- 以 `直线穿透`、`多段压线`、`移动后伤害兑现` 为主
- 是最能体现“站位对了，一枪吃整条线”的高光分支

#### 基础长矛专长

- 基础技能：`突刺`
- 技能效果：对前方直线上的 `2 个敌人` 造成伤害

#### 高级长矛专长

- 功能技能候选：`连续刺击`
- 技能定位：在一定范围内可以选择多个目标的多段攻击技能
- 专长强化：
  - `突刺` 可对前方直线上的 `3 个敌人` 造成伤害
  - `连续刺击` 获得后，作为长矛线的多目标多段表达

#### 大师长矛专长

- 终局技能候选：`三连刺`
- 技能定位：扇形攻击区域的 AOE，高伤害，高消耗
- 专长强化：
  - `突刺` 根据亚马逊在攻击前移动的格数提高伤害
  - 攻击结算后，该移动计数重置
  - `连续刺击` 在大师阶段额外增加 `1 段攻击`
  - `三连刺` 作为长矛线的终局范围爆发技

### 分支 2：投枪猎杀

定位：

- 远程投掷副核主线
- 以 `单体高伤`、`关键目标处理`、`标枪回收节奏` 为主
- 用来弥补亚马逊在敌人分散、无法近战吃线时的解题能力

#### 基础投枪猎杀

- 基础技能：`毒矛`
- 技能效果：远程直线投射物，碰撞到单位后造成伤害并施加 `中毒 debuff`

#### 高级投枪猎杀

- 功能技能候选：`回收长矛`
- 技能定位：在一定范围内直接回收长矛
- 专长强化：
  - `毒矛` 可穿透 `1 个敌人`
  - 让投枪线从“单次投射”推进到“可持续远程压制”

#### 大师投枪猎杀

- 终局技能候选：`雷神之怒`
- 技能定位：丢出的长矛化身闪电，击中第一个单位后分裂继续发射（分裂方向和数量待定）
- 专长强化：
  - `回收长矛` 提升为 `全地图范围`
  - `毒矛` 在最后命中的敌人处产生 `毒雾`
  - `毒雾` 范围内敌人获得 `中毒 debuff`
  - `毒雾` 持续 `2 回合`

### 分支 3：被动与魔法专长

定位：

- 非直接武器主输出线
- 通过被动、分身、变身等手段补足亚马逊的生存、节奏与爆发窗口
- 不与长矛 / 投枪直接抢主输出身份，但决定她能否稳定活到高光回合

#### 基础被动与魔法专长

- 基础技能：`战斗技巧`
- 技能定位：被动技能
- 技能效果：增加 `30% 闪避率`

#### 高级被动与魔法专长

- 功能技能候选：`分身`
- 技能定位：在自己的位置产生一个 `50% HP` 的分身吸引原先敌人的攻击，自己后撤到旁边合法格
- 专长强化：

#### 大师被动与魔法专长

- 终局技能候选：`变身女武神`
- 技能定位：生命值提高 `40%`，攻击提高 `40%`，持续 `5 回合`
- 专长强化：
  - `战斗技巧` 额外获得 `20% 暴击率提升`
  - `分身` 升级后会清除自身 `debuff`

## 中上层 Build 框架 v1

以下内容用于约束三职业在 pure run 中的成长方式，优先级高于单个技能的实现细节。

### 升级包结构

每次升级固定发放：

1. `+1 属性点`
2. `专长二选一`
3. `技能二选一`

### 属性规则

- 保留现有 `7 维属性` 与 `中性值 5`
- `Strength / Agility` 的旧规则只保留给：
  - 近战普通攻击
  - 远程普通攻击
  - 少数基础物理动作
- 所有 `技能` 不再吃全局“近战/远程”规则
- 每个技能只绑定 `一个主属性`
- 技能数值公式：`基础值 + 主属性 × 系数`
- 属性只影响 `数值强度`
- 属性不改变：
  - 范围
  - 形状
  - 距离
  - 命中数
  - projectile 行为

### 专长规则

- `专长` 改名自旧“被动技能”
- 专长有三个阶段：`基础 / 高级 / 大师`
- 三个阶段为 `递进替换关系`，不是并列持有
- 每个职业至少拥有 `3 条职业专长线`
- 每条职业专长线的 `基础专长` 都会自动解锁 `1 个基础技能`
- 所有职业的首轮入场规则统一：`从该职业的基础专长线中随机选择 1 条，并自动获得对应基础技能`
- 专长负责：
  - 定义 build 方向
  - 解锁技能候选权限
  - 强化已有技能

### 专长强化范围

- 允许 `数值强化`
- 允许 `规则强化`
- 不直接改变技能几何骨架

### 技能规则

- `技能` 改名自旧“主动技能”
- 技能默认只有“已获得 / 未获得”两种状态
- 但对 `由专长解锁的特殊技能`，允许使用轻量级升级规则：
  - `基础技能`：可升级 2 次
  - `高级技能`：可升级 1 次
  - `大师技能`：不可升级
- 该规则不是全局适用，而是仅限于“专长明确解锁出来的特殊主动技能”
- 大部分专长本身不会直接提供主动技能，因此也不会受到这套技能升级规则约束
- `高级 / 大师技能` 本身进入候选时，仍然占用 `技能二选一`
- 这类特殊技能在已经获得之后，后续升级 `不占用技能二选一`
- 当对应专长阶段升级时，已获得的特殊技能自动升级
- 需要有独立的升级提示窗口；该窗口可以合并在 `技能二选一` 选择界面内呈现，但逻辑上必须与候选技能选择分离
- 第一版本的临时规则：`大师专长` 可以正常进入候选并被获得，但若对应的 `大师技能` 尚未实现，则该阶段暂时不提供大师技能候选
- 在这种情况下，大师专长只先承担“强化已有技能 / 强化该分支上限”的作用，待后续版本再补入对应大师技能
- 技能进入候选池需要同时满足：
  - `专长前置`
  - `主属性值限制`

### 专长池结构

专长池由两部分组成：

1. `职业大分支专长`
2. `通用专长`

其中职业专长采用 `少量大分支` 方案，例如法师可拆为火/冰/电等主 build 线。

### 专长候选生成规则（当前已定）

- 采用 `固定池抽取`
- 不是预设成长表逐级硬推
- 过滤条件：
  - 满足前置条件
  - 满足主属性值限制
- 来源规则：
  - 职业专长与通用专长都进入固定池
  - 当前不再区分职业权重、职业类别权重或技能类别权重
  - 满足过滤条件的候选按同等权重参与抽取

### 职业专长的阶段门槛规则

- `高级` 与 `大师` 专长不只看前置，还要看 `专长主属性` 是否达到门槛
- 该门槛使用 `角色基础属性值` 判断
- 不计入：
  - 装备加成
  - 临时 buff
  - 其他战斗内短时增益

这意味着：

- `基础专长` 主要承担 build 起点选择
- `高级 / 大师专长` 通过主属性门槛控制进入固定池的时间点
- 即使前置已满足，若主属性值不足，也不会进入专长候选池

统一阶段门槛：

- `基础`：主属性达到 `5`
- `高级`：主属性达到 `7`
- `大师`：主属性达到 `9`

说明：

- 该门槛适用于职业专长与通用专长
- 当前不再为不同职业、不同专长类别单独设置不同门槛表

### 与升级节奏的联动

- 当前额外确认一条高层规则：`每场战斗后只有一个角色可以升级`
- 每次升级只给 `+1 属性点`
- 当前不再额外限制“每张地图最多升级几次”

这意味着专长推进速度的主要限制，来自：

1. 升级名额稀缺
2. 专长主属性门槛
3. 技能 / 专长候选池的前置过滤

这条规则带来的结果是：

- 单个角色进入高级 / 大师专长不会过快
- 队伍内三人不容易同时高速冲到各自分支的高阶阶段
- 在正常三人都存活的情况下，要把角色推进到大师专长本身就需要较多战斗与较多属性投入，不需要再用地图升级次数做硬限制
- 若队伍出现减员，剩余角色更快进入大师专长，反而可以作为对减员损失的自然补偿

这条规则的设计价值在于：

- 不靠纯随机稀释，也不靠“每图固定升级上限”来限制高阶专长
- 而是通过 `升级机会稀缺 + 属性门槛 + 前置过滤` 来控制 build 推进速度
- 同时强化“本局资源倾斜给谁”这一 pure run 核心判断

### 通用专长的属性门槛规则

- `通用专长` 同样需要属性门槛，不走“只有前置、没有属性要求”的路线
- 但通用专长的门槛不按单个专长逐个随意指定，而是 `按专长类别统一绑定属性`

这意味着通用专长后续在设计时，应先定义类别，再统一定义对应的主属性门槛。示意例如：

- 生存类通用专长 -> 体质
- 机动类通用专长 -> 速度
- 暴击 / 赌运类通用专长 -> 幸运
- 法力 / 施法效率类通用专长 -> 智力或魅力

采用这种规则的原因是：

1. 保持职业专长与通用专长的门槛体系一致
2. 避免通用专长因为门槛松散而反客为主
3. 让玩家更容易理解“我堆这个属性，会更容易进入哪类通用专长池”

这表示职业专长仍是 build 主轴，而通用专长作为跨职业变化源进入同一个抽取体系，但不再享有单独权重修正。

### 待继续收敛的规则

以下仍需继续 grill 后定稿：

1. 拿到基础职业专长后，后续更高阶段职业专长是否提升抽取权重
2. 已选主分支是否应获得保底候选，避免成长方向漂移
3. 通用专长允许承担到什么程度的功能：纯强化、通用技能，还是两者兼有

## 通用专长池候选 v1（被动版）

本节明确：当前讨论的“通用专长”优先参考 `Mewgenics` 的 `colorless_passives.gon`，而不是 `colorless_abilities.gon`。也就是说，本轮优先参考的是跨职业被动能力，而不是通用主动技能。

### 当前采用的通用专长大类

- `生存类`
- `资源类`
- `暴击 / 机会类`

说明：

- `机动类` 暂不纳入首轮通用专长池，避免与法师的瞬移术、未来野蛮人的跳跃等职业标志技能冲突。
- `协同强化类` 暂不纳入首轮通用专长池，避免抢占职业专长本应承担的队伍关系设计。
- `独狼天赋` 保留为 TODO，视为规则改写型专长，后续单独设计，不进入首轮普通通用池。

### 生存类通用专长

#### 1. 自然愈合

参考倾向：`NaturalHealing` / `HealthRegenUp`

属性类别：`体质`

定位：

- 稳定续航
- 降低连续战斗的磨损压力
- 不参与爆发，只改善长线推进容错

阶段效果：

- `基础`：战斗结束后增加 HP 和 MP 回复量
- `高级`：每回合结束后增加 HP 和 MP 回复量
- `大师`：同时增加战斗后与每回合结束时的回复量数值

说明：

- 该专长当前作为 pure run 连战节奏的核心生存向通用专长之一
- 它服务的是“能不能继续推进”，不是“单场能不能翻盘”

#### 2. DeathProof 型专长（名称待定）

参考倾向：`DeathProof` / `ChanceToRevive`

属性类别：`体质`

定位：

- 一次性保命
- 提供高光容错
- 不应成为稳定收益来源

阶段效果：

- `基础`：每场战斗仅限一次，濒死时保留 1 HP
- `高级`：同样每场战斗仅限一次；触发后获得一个 `1 回合伤害护盾`（待实现）
- `大师`：同样每场战斗仅限一次；触发后获得一个 `1 回合圣盾`（无敌）

说明：

- 当前已明确三个阶段都必须保留“仅限一次”的硬限制
- 这是为避免其变成泛用最优生存解

### 资源类通用专长

#### 3. 资源效率专长（名称待定）

参考倾向：`Study` / `Unrestricted` / `Brainstorm` 的被动化理解

属性类别：`魅力`

定位：

- 改善施法和技能循环压力
- 为法师和死灵法师提供更稳定的技能经济

说明：

- 当前只保留类别与定位
- 具体阶段效果仍待后续补完

阶段效果：

- `基础`：技能法力消耗小幅降低
- `高级`：技能法力消耗进一步降低
- `大师`：每回合首次施法固定返还少量法力

说明：

- 大师阶段当前明确采用 `固定返还`，不是按技能消耗比例返还
- 这样更容易控制强度，也更容易让玩家预估回合内资源节奏

#### 4. 战后资源 / 掉落专长（名称待定）

参考倾向：`MetalDetector`

属性类别：`幸运`

定位：

- 改善本局运营资源
- 提高战斗外资源收益

说明：

- 该类偏 run 层，不是首轮最优先的战斗表达专长
- 可保留为次优先级的通用资源向选择

#### 4. 收割回复

参考倾向：`KillsHeal` / `SoulReap` 的击杀回收思路

属性类别：`幸运`

定位：

- 奖励击杀
- 把“打顺了”转化为更稳定的连续推进能力
- 同时连接战斗内收益与战后续航节奏

阶段效果：

- `基础`：击杀后只恢复少量 HP
- `高级`：击杀后恢复更多 HP，并少量恢复 MP
- `大师`：击杀后恢复进一步提升，并获得一个短时小增益

说明：

- 基础版当前已明确不恢复 MP，只恢复 HP
- 这样可以避免它在首轮过早变成法系和物理系都无脑通吃的万能资源专长

### 暴击 / 机会类通用专长

#### 5. 幸运汲取

参考倾向：`LuckDrain`、部分 `SelfAssured` 的成长思路

属性类别：`幸运`

定位：

- 将战斗中的击杀与暴击节奏转化为幸运成长
- 让幸运流成为一种明确但不稳定、但可逐步蓄势的成长方向

阶段效果：

- `基础`：自己击杀单位时，获得 1 层 `幸运增益`
- `高级`：任意敌方单位死亡时，获得 1 层 `幸运增益`
- `大师`：每累计 3 层 `幸运增益`，获得一个 `下次攻击必定暴击` 的 buff；暴击后该 buff 消失，幸运计数重置

说明：

- `幸运增益` 的具体数值效果待后续细化，但当前定位已明确为幸运向的可堆叠成长资源
- 大师阶段的核心不是永久提升，而是把幸运积累转化为一次确定性的暴击兑现窗口

#### 6. 过度自信

参考倾向：`OverConfident`

属性类别：`幸运`

定位：

- 在理想状态下提供高收益
- 通过“未受伤”这一条件制造高风险高回报的机会流

阶段效果：

- `基础`：获得暴击率提升
- `高级`：只要在一场战斗内 `没受伤`，该效果就持续激活
- `大师`：效果失效后，如果连续 `3 回合没受伤`，还能重新激活

说明：

- 与 `幸运汲取` 不同，`过度自信` 不依赖击杀滚雪球，而依赖角色是否能维持完美状态
- 该专长更适合法师或偏谨慎站位的高风险玩法，不适合作为所有职业的默认最优选择

### 暂缓 / TODO

- `领导术` 暂缓：原先“回合结束后概率额外获得一个新回合”的方案强度和规则改写程度都过高，暂不进入首轮通用专长池
- `独狼天赋` TODO：默认可行动两回合、默认属性值提高 40%、且要求队伍中只能有一个成员，多于一个时失效。该方案属于规则改写型专长，后续单独设计，不纳入普通通用池

## 装备与消耗品来源

本原型不采用“战后奖励三选一”作为主成长来源，而采用更贴近冒险的混合来源：

1. 怪物死亡掉落
2. 宝箱开启掉落
3. 商店购买
4. 探索过程中的地图掉落

这样做的目的有三个：

1. 保留战棋冒险中的现场收获感
2. 让路线、战斗表现和资源经营都能影响构筑
3. 让星图探索不只是通往下一场战斗的过道

## 推进压力

搜打撤中的“撤离张力”被拿掉后，本原型改用 `血量/资源磨损` 承担推进压力。

### 压力来源

- 角色 HP 损耗
- 技能资源损耗
- 消耗品库存消耗
- 连续遭遇后的恢复机会稀缺

### 设计目标

- 让玩家不是在问“能不能带出去”，而是在问“现在这支三人小队还能不能继续往前打”
- 让推进决策建立在小队整体状态上，而不是单角色数值上
- 让资源磨损成为推动路线权衡和补给选择的核心动力

### 风险边界

资源磨损不能退化成单纯的补给税。它必须让玩家感受到：

1. 当前路线值得冒险
2. 当前补给机会有真实价值
3. 当前小队状态会改变后续节点偏好

## 核心循环

本方向的最小有效循环如下：

1. 在星图上选择路线或节点
2. 进入战斗、事件、商店或补给机会
3. 获得技能、装备、消耗品或状态变化
4. 重新分配三人小队的资源与职责
5. 判断是否继续推进更高风险区域

这个循环的重点不再是“带出”，而是“当前 run 是否越来越成型”。

## 成功标准

本方向成立，至少要观察到以下信号：

1. 玩家愿意为了尝试另一种三人配置而立刻重开一局
2. 每次装备掉落都会产生“给谁穿”的真实讨论
3. 每次技能成长都会影响小队分工，而不是只提升个人效率
4. 星图路径选择会被当前小队状态影响
5. 资源磨损会改变玩家对战斗、商店和补给节点的偏好

补充正式判据：

- 在 pure run 三人小队原型中，一条路线或节点选择，只有在结算后不会把当前小队压缩到仅剩单一、被迫的后续解法，并且能够通过恢复、消耗品补充、技能/天赋/属性成长或经济转化，扩宽、恢复或强化下一轮的合理解法集合时，才应被视为当前 run 中的合理选择。
- 若一次结算能够稳定改变玩家下一轮的合理解法集合，使玩家既未被压缩为单一路径求生，又因 `HP/MP/死亡状态`、`消耗品变化`、`技能/天赋/属性成长`、`金币/商店机会` 中的一类或多类结果而主动重配三人职责、调整风险偏好或改写路线优先级，则可视为 pure run 的“三人构筑 -> 再选择”闭环开始成立。

## 失败标准

以下现象出现时，应视为该方向尚未成立：

1. 三人只是三个独立角色并排前进，没有协同构筑感
2. 装备只看品质与数值，不会引出分配决策
3. 技能成长只让角色更强，但不改变小队打法
4. 星图推进只是走格子，和当前小队状态弱相关
5. 资源磨损只让玩家烦躁，并没有制造有意义的策略压力

补充正式判据：

- 若结算结果虽持续发生，但既未改变三人小队下一轮的合理解法集合，也未促使玩家重新分配队内资源、重估路线风险或调整角色职责，则不应视为 pure run 构筑闭环成立。
- 若玩家在多次循环后仍长期沿用同一种路线逻辑，只把成长 action 当作数值增强，而不会因为新的技能/天赋/属性组合去主动挑战更高价值路线，或因为状态受损而转向更稳健路线，则说明小队构筑尚未进入地图决策层。

## 与搜打撤方案的本质差异

这条 pure run 方向，验证重点和原先搜打撤方案完全不同：

- 原方案问：玩家是否愿意为了带出收益承担风险
- 新方案问：玩家是否愿意为了尝试新构筑反复重开

- 原方案的奖励价值来自“可保存”
- 新方案的奖励价值来自“本局立刻改变打法”

- 原方案的高压点来自“亏不亏”
- 新方案的高压点来自“小队还能不能继续推进”

因此两者不能混着评估，必须用不同的成功标准看待。

## 对 Task 1 基线的替换说明

`2026-06-24-short-term-prototype-task1-design.md` 仍然保留为原始验证基线记录，但在 pure run 分支下，以下表述需要被替换理解：

1. `结算 -> 带出 -> 再入局` 改为 `节点收益 -> 小队重配 -> 继续推进`
2. `撤离张力` 改为 `血量/资源磨损压力`
3. `愿不愿意带出收益` 改为 `愿不愿意立刻重开尝试另一种构筑`

这样做的目的，是保留讨论历史，同时明确当前分支的验证口径已经变化。

## 原型阶段非目标

以下内容不应在本轮原型中优先证明：

- 完整职业阵容
- 大型装备池
- 复杂剧情与事件文本
- 长期局外解锁体系
- 精细数值平衡
- 正式终局内容

原型阶段只需要证明：三人小队的 run 内构筑是否足够让人反复开局。

## 推荐的下一步设计主题

如果继续沿此方向推进，下一轮最值得细化的是：

1. 固定三人小队的职业分工模型
2. 装备槽与消耗品槽的最小方案
3. 资源磨损如何在星图推进中制造节奏
4. 战斗外掉落如何确保“马上改变打法”

补充观察口径建议：

- 观察玩家在每次结算后，下一轮是否仍保有至少两种他认为“都说得通”的小队推进方案；若没有，是哪类资源或状态把他压缩成了单一路径。
- 观察玩家改变路线时，主要是因为哪一类结算结果：`HP/MP/死亡状态`、`消耗品变化`、`技能/天赋/属性成长`，还是 `金币/商店机会`。
- 观察玩家是否能明确说出：当前选择这条路线，是在修复哪个痛点，还是在放大当前哪种三人组合优势。
- 观察玩家是否会因为刚形成的技能/装备/职责组合，而主动提高风险偏好、改走更高收益路线；若不会，说明成长尚未真正进入地图决策层。

## 法师三系分支骨架 v1

### 总规则

- 法师开局从 `火 / 冰 / 电` 三系中随机获得一个 `基础专长`
- `基础专长` 的职责统一为：
  - 发放该系 `入场技能`
  - 确定当前法师的分支起点
- `高级专长` 的职责统一为：
  - 打开该系的功能型技能候选
  - 强化该系前一阶段技能
- `大师专长` 的职责统一为：
  - 打开该系终局技能候选
  - 对整条分支已有技能做最终强化

### 火系分支

- `基础火魔法`
  - 入场技能：`火球术`
  - 基础职责：让法师一开局就拥有单点爆裂 + 点燃的伤害手段
- `高级火魔法`
  - 功能技能候选：`召唤火魔`
  - 分支职责：从直接伤害推进到场面持续输出
  - 对已有技能的强化：
    - 继续提高 `火球术` 的主命中伤害
    - 继续提高 `点燃` 层数
    - 让火系基础输出与火魔形成持续火压场面
- `大师火魔法`
  - 终局技能候选：`陨石术`
  - 分支职责：把火系路线推到大范围高爆发清场
  - 对已有技能的强化：
    - 继续强化 `火球术` 的点燃兑现能力
    - 强化 `召唤火魔` 的持续场面价值
    - 让整条火系路线从单点爆裂推进到范围清场终局

### 冰系分支

- `基础冰魔法`
  - 入场技能：`寒冰箭`
  - 基础职责：让法师一开局就拥有单点伤害 + 减速的节奏控制手段
- `高级冰魔法`
  - 功能技能候选：`冰甲`
  - 分支职责：从单点控场推进到自保与压制并存
  - 对已有技能的强化：
    - 继续提高 `寒冰箭` 的减速持续时间
    - 让冰系前期控制更稳定
    - 让冰甲进入后，冰系从拖节奏过渡到“拖节奏 + 站得住”
- `大师冰魔法`
  - 终局技能候选：`暴风雪`
  - 分支职责：把冰系路线推到区域减速 / 冻结 / 压场
  - 对已有技能的强化：
    - 强化 `寒冰箭` 的控制价值
    - 强化 `冰甲` 的保命与反近战收益
    - 让 `暴风雪` 成为冰系的区域终局表达

### 电系分支

- `基础电魔法`
  - 入场技能：`霹雳闪电`
  - 基础职责：让法师一开局就拥有单点伤害 + 麻痹的高节奏打断手段
- `高级电魔法`
  - 功能技能候选：`瞬移术`
  - 分支职责：从单点打断推进到高机动调位与保命
  - 对已有技能的强化：
    - 继续提高 `霹雳闪电` 的麻痹触发概率
    - 让电系从单点打断过渡到打断 + 高机动解场
- `大师电魔法`
  - 终局技能候选：`连锁闪电`
  - 分支职责：把电系路线推到点杀后扩散、连锁收场
  - 对已有技能的强化：
    - 强化 `霹雳闪电` 的打断价值
    - 强化 `瞬移术` 的节奏收益
    - 让 `连锁闪电` 承担电系的多目标终局兑现
