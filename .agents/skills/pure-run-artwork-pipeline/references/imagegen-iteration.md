# ImageGen 单图迭代

## 输入图片职责

每次调用前给输入图命名并写清职责：

- **母图**：锁定角色身份、胶囊身体、等距站位和已确认装备；编辑请求必须写出保持不变的区域。
- **犬种/脸部参考**：只迁移耳型、口鼻、眼神和颜色，不迁移参考图比例或完整躯干。
- **武器/姿态参考**：只迁移握点、杆刃结构或骨架；禁止复制写实材质、地图和对方角色。

## 迭代规则

一次只生成一个角色或一个变体。先锁定身体和脚位，再逐步编辑脸部、武器、遮挡层和颜色；在提示中重复标准画布、脚底基线和“胶囊身体不可重绘”。

局部修改要明确屏幕方向与三维层级，例如“枪杆主体在盾牌后，只有枪头在盾牌前”。如果编辑结果改变了头身比例、脚位或身体宽度，回退到最近的正确母图，不继续在错误候选上叠加修改。

## 外部物件

将武器、耳朵、翅膀和法术当作独立剪影处理：规定长度上限、离地状态、画布安全边距和与身体的前后层级。生成后优先检查 128 预览能否把手、物件尖端、脸和脚分开；不能分开时先调整位置或版本，而不是增加内部排线。
