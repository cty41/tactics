# Sprite 尺寸契约

## 发布规格

| 项目 | 母版 | 预览 |
| --- | --- | --- |
| 画布 | `256×256 RGBA` | `128×128 RGBA` |
| 标准完整轮廓 | `122 px` 高 | 约 `62 px` 高 |
| 脚底基线 | `y=236` | `y=118` |
| 身体水平锚点 | `x=128` | `x=64` |
| Tile Review | `64×32` 线框 | 同一线框 |

完整轮廓高度按 alpha 非透明像素的包围盒计算，主要用于画布安全、裁切和技术校验；它不是跨犬种比较主体体量的唯一依据。跨角色校对优先比较核心胶囊主体的上缘、下缘、宽度和中心，排除耳朵、脚掌、武器、盾牌、法杖、翅膀和特效。角色保持右下 `45°` 等距方向；两脚可以沿等距对角线错开，但不能悬空或下沉。

## Godot 运行时映射

标准角色导入到 `godot/assets/units` 时，`256×256` 角色纹理保持项目统一尺寸，并通过 Unit Resource 的脚底锚点对齐；`122 px` 可见轮廓约等于两格 Tile 高。

地面 Tile 保持 `64×32` 契约。不要修改 Tile、Grid、相机或角色节点缩放来补偿角色导入比例；先校正纹理和脚底基线。

单位 actor 根节点和 `Sprite2D` 子节点保持单位缩放。状态反馈绘制在程序化等距 Tile 高亮层，不使用方形角色 Marker；阴影以 Unit Resource 的脚底锚点为准，仅允许极小下偏移。

## Tile Review 落点

Tile QA 必须复现游戏内的逻辑落点，而不是把 Sprite 按可见包围盒居中到棋盘截图中：

- `64×32` Tile 的几何中心是单位所在 Grid Cell 的落点。
- 地面单位把母版脚底锚点 `(128,236)` 或预览锚点 `(64,118)` 精确放在目标 Tile 的几何中心。
- 飞行单位仍使用同一虚拟落点；球核中心、虚拟落点和 Tile 中心必须位于同一垂直轴线。可见球核或身体下沿应位于中心上方，悬浮间距不能通过下移 Sprite 消除。
- 球形飞行单位的落地死亡图不再使用活体悬浮锚点；保持约为已批准活体球核 `75%–85%` 的近圆球核、头部线索朝右上和贴地双翼，并以完整死亡尸体 AABB 中心映射到目标 Tile 几何中心。
- QA 棋盘使用每列/行相差 `(32,16)` 的错列等距中心，不得用 `64×32` 图片组成普通矩形网格冒充 Tilemap。
- 对比图可以改变画布尺寸，但不得改变 Sprite 内部锚点、缩放比例或基线。

例如目标 Tile 中心为 `(128,160)` 时，`128×128` 预览应粘贴到 `(64,42)`，使其局部锚点 `(64,118)` 映射为 `(128,160)`。

## 外部轮廓

标准校准优先保持胶囊身体的高度、中心和脚位。长矛、刀、耳朵、翅膀、法杖和特效可能改变横向包围盒；如果使完整轮廓超出 `122 px`，必须标记为 `candidates`，不能伪装成发布 Sprite。候选 Review 报告应同时记录身体包围盒和外部轮廓包围盒。

## 核心体量校对

方向变体以同角色已确认的 `down-right` 作为唯一只读体量对照，先制作纯核心主体蒙版，再人工检查核心胶囊主体的上下缘、中心、最大宽度及上中下三个截面宽度。蒙版必须排除耳朵、口鼻、眼睛、手掌、脚掌以及所有装备或特效；主体下缘不包含脚掌，脚掌只负责统一落地基线。蒙版只用于测量与 QA 叠加，禁止参与最终图像合成。完整 alpha 包围盒只能用于画布安全和裁切检查，不能用于推导核心比例或执行方向图缩放。

方向变体必须展示核心蒙版双色叠加；主体上缘、下缘和最大宽度误差默认不超过 `2–3 px`，中心误差不超过 `1–2 px`，上中下截面的宽度趋势必须一致。中段近似平行，下段不得宽于中段；禁止梨形、窄柱体或为迁就装备而缩放核心。采用无手臂设计时，两只手掌必须与主体形成多像素重叠接触面并保持 alpha 连通，禁止浮空、单像素切点或细线连接。每次只处理一个角色，核心叠加通过后再展示母版并排、`128×128` 预览和 `64×32` Tile QA，获得人工确认后才开始下一个角色或对应方向变体。

飞行单位以球核取代胶囊主体进行体量判断。球核中心固定为母版 `x=128`、预览 `x=64`，翅膀只接受画布安全与裁切检查，不参与水平居中。小型飞行单位可以采用普通地面单位核心体量的约 `75%`；球核中心的垂直位置对齐基准胶囊体上部圆帽中心，而不是把球核下沿贴近基线。其虚拟落点保持在 `(128,236)` 或 `(64,118)`，并与球核中心保持同轴，使悬浮高度在 Tile QA 中明确可读。

## 文件配对

每个发布母版都要有同名 `_128.png` 预览，例如：

```text
doge_capsule_hunter_color_v01.png
doge_capsule_hunter_color_v01_128.png
```

等比缩小，不能单轴拉伸。Tile 参考资产可使用 `64×32`，但不应被当作角色 Sprite 或与角色母版配对。
