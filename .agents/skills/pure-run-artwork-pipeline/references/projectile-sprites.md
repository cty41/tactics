# 投射物 Sprite

投射物是独立的中心锚点素材，不使用角色脚底基线。一次只生成一个投射物；当前投射物未获人工确认前，不得开始下一个。

## Quick Reference

| 项目 | 规则 |
| --- | --- |
| 生成节奏 | 单图生成、单图 Review、明确确认后再生成下一张 |
| 母版与预览 | `256×256 RGBA` 与 `128×128 RGBA` 成对保存 |
| 锚点 | 母版中心 `(128,128)`，预览中心 `(64,64)` |
| 尺寸依据 | 与施法者 `_128` 的主体可见体量比较，不按孤立固定像素拍脑袋 |
| 方向 | 有方向轮廓保留一张标准朝右图，Tile Review 时按飞行向量旋转 |
| 动画 | 基础投射物默认单帧；平移和旋转留给未来运行时 |
| 去幕 | 去幕与缩小后都要清零 `alpha=0` 像素 RGB，并检查精确幕色 |

## 输入职责

- **施法者正式图**：只提供职业配色、线宽和已确认的法术视觉语言，不迁移角色、手掌、武器或身体。
- **形状描述**：锁定投射物轮廓、朝向和尾迹长度；不得让 ImageGen 从施法者装备重新发明另一件实体武器。
- **当前候选**：只承担单项修改，例如尺寸、尾迹或色块；错误候选不能成为下一种投射物的母图。

## Workflow

1. 从 `calibrated/approved` 选择施法者正式图，声明它只负责颜色与线条。
2. 一次 ImageGen 只生成一个投射物，使用纯绿幕或洋红幕，禁止角色、地面、阴影、文字和命中特效。
3. 去幕后先锁定轮廓与色块，再按施法者 `_128` 主体宽高计算合理占比；不要先规定固定 AABB 再强迫角色适配。
4. 将等比缩放后的投射物放到画布中心；有方向投射物的原生版本统一朝屏幕右侧。
5. 生成 `_128` 预览，在真实 `64×32` 错列 Tilemap 中按攻击方向旋转并放在施法者前方；同时展示施法者，不能孤立判断大小。
6. 清理透明像素、检查精确幕色和中心偏差，展示给用户。获得明确确认前停止，不生成下一张。
7. 确认版本保留在 `concepts`；被替代版本移至 `rejected/superseded`，不覆盖或删除历史。

## 尺寸与 Tile Review

- 投射物使用自身可见 alpha AABB 判断大小，但必须以同一 `_128` 画面中的施法者主体为比例基准。
- 基础攻击应清晰可读但不能抢过角色。已确认的法师奥术弹 `v02` 在 `_128` 中约为 `22×10 px`，对应法师主体 `53×62 px`，宽度约为主体的 `42%`。
- Tile Review 只使用 `_128` 预览。投射物中心放在攻击路径上；有方向素材按 Tile 轴旋转，不能只把朝右原图水平摆在等距棋盘上。
- 投射物中心不是目标 Tile 的站立脚底点，也不使用 `y=118`。未来运行时应使用中心 Pivot `(0.5,0.5)`。
- 对旋转后的完整 AABB 只检查遮挡和安全距离，不据此反向缩放原始投射物。

## 去幕与重采样

- 色幕去除后，必须将图像重新合成到同尺寸的透明黑底画布，确保所有 `alpha=0` 像素的 RGB 为 `(0,0,0)`。
- 仅使用 ImageMagick 的 `-alpha background` 不足以保证透明像素 RGB 为零；应使用透明黑底 `Over` 合成或等效的确定性处理。
- Mitchell 缩小会扩大抗锯齿 alpha AABB，并可能重新引入带色透明像素。预览生成后必须再次进行透明黑底合成和精确幕色检查。
- 验收同时检查：RGBA、透明四角、精确绿/洋红像素为零、透明非黑 RGB 为零、中心偏差不超过 `1 px`。

## 静态法术与飞行轮廓

- 手持或悬浮的静态鬼火可以保持近圆主体并让短火舌自然向上；它只负责确认职业身份、配色和火焰语言。
- 飞行投射物必须把火舌转到飞行反方向。标准原生图朝画面右侧飞行时，亮核略靠右，短火舌向画面左侧拖曳。
- 流线化只改变外焰轮廓，不把圆润能量核心拉成尖头。尾焰默认不超过完整可见长度约三分之一，避免与法师的短梭形奥术弹趋同。
- 已确认死灵飞行版 `v03` 的 `_128` 可见 AABB 约为 `22×13 px`，对应死灵主体约 `56×62 px`；中心 Pivot 由运行时沿飞行向量旋转。

## Anti-patterns

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 一次生成多个职业投射物 | 风格和尺寸无法逐项归因 | 前一张确认后再生成下一张 |
| 只看孤立 AABB | 投射物在角色旁过大或过小 | 与施法者 `_128` 和 Tilemap 同屏判断 |
| 对所有职业使用同一固定尺寸 | 职业轮廓与视觉重量失衡 | 按角色体量和投射物形状单独校准 |
| 把角色图当编辑母图 | ImageGen 带入角色、法杖或手掌 | 明确角色图只负责配色与线条 |
| 把手持鬼火直接当飞行图 | 火舌仍向上，运动方向不清晰 | 保留静态造型锚点，另做火舌逆向的飞行版 |
| 为了流线感拉尖能量核心 | 与奥术弹或实体飞镖混淆 | 只让短尾焰后掠，前部核心保持圆钝 |
| 中心素材套用脚底基线 | 飞行路径发生垂直偏移 | 使用画布中心与未来中心 Pivot |
| 缩小后不再清理 alpha RGB | 旋转、采样或压缩时出现色边 | 预览重采样后再次透明黑底合成 |
| 在 Tilemap 中不旋转方向素材 | 无法判断真实攻击方向和占用 | 按等距攻击轴旋转后 Review |
