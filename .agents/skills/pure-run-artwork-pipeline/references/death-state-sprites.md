# 死亡状态 Sprite

死亡图是独立的静态状态素材，不是将站立图旋转、压扁或镜像后的结果。生成前必须先判断角色的核心拓扑，再选择对应的体量和朝向约束。

## Quick Reference

| 问题 | 规则 |
| --- | --- |
| 先看什么 | 先分类核心拓扑，再锁定角色母图 |
| 胶囊地面单位 | 仰面平躺、头朝画面右上、身体轴约 `60°`、短厚且不弓曲 |
| 球形飞行单位 | 保持近圆球核，只让耳朵、脸等头部线索朝右上；双翼瘫软贴地 |
| 如何比较大小 | 只比较胶囊核心或球核，不包含耳、四肢、武器、盾牌、法杖、翅膀和特效 |
| 死亡道具 | 必须脱手；最多保留任务明确批准的单件识别道具 |
| Tile 锚点 | 使用完整死亡尸体 AABB 中心，不使用站立脚底锚点或活体悬浮锚点 |
| 输出状态 | 未经人工确认只进入 `concepts` 或 `candidates`，不接入 Unity |

## 先分类核心拓扑

| 拓扑 | 身份与体量母图 | 共享的死亡方向 | 禁止迁移 |
| --- | --- | --- | --- |
| 胶囊地面单位 | 同角色已确认活体图；赤柴死亡图用于已确认的倒地体量与姿态 | 脸和胸腹朝上，头朝右上，身体轴约 `60°` | 站立图直接旋转、侧躺、镜像、弓背、细长化 |
| 球形飞行单位 | 同角色已确认活体球核 | 耳朵、脸等头部线索朝右上；翅膀同步旋转并落地 | 赤柴胶囊轮廓、四肢结构、细长身体轴、按翼展缩放球核 |

赤柴死亡图不是所有角色的通用身体母图。它对胶囊地面单位提供倒地姿态和紧凑体量参考；对球形飞行单位只提供屏幕方向。

## 输入图片职责

| 输入 | 负责 | 不负责 |
| --- | --- | --- |
| 已确认活体角色图 | 身份、配色、脸部、核心拓扑、核心体量和职业物件清单 | 死亡姿态 |
| 已确认赤柴死亡图 | 胶囊尸体的方向、平躺姿态和紧凑度；球形单位的头部屏幕方向 | 替换其他角色身份；把球核改成胶囊 |
| 当前候选 | 作为明确的局部编辑目标 | 替代已确认母图或成为新的尺寸真相 |
| `rejected`、`superseded`、案例快照、`tmp` | 只用于识别失败模式 | 任何后续生成母图 |

每次 ImageGen 调用都要在提示中分别命名“身份母图”“方向参考”和“局部编辑目标”，并写明每张图禁止迁移的内容。

## Workflow

1. **分类拓扑。** 明确是胶囊地面单位还是球形飞行单位。
2. **锁定核心。** 从已确认活体图记录胶囊核心或球核的宽高、中心和轮廓；排除所有外部特征。
3. **生成单个死亡图。** 一次只处理一个角色，保留身份，重建死亡姿态；不要批量生成。
4. **先验收核心，再处理道具。** 核心不合格时回到正确母图重生，不在错误候选上连续旋转、拉伸或修补。
5. **处理脱手道具和特效。** 只保留明确批准的单件道具，移除常驻法术、火焰、鬼火、粒子和光晕。
6. **去幕并缩小。** 清零全透明像素的 RGB，再生成 Mitchell `_128` 预览；缩小后再次清理精确色幕残色。
7. **Tile Review。** 使用 `_128` 预览，以完整尸体 AABB 中心对准 `64×32` Tile 几何中心，并与已确认死亡图并排比较。
8. **归档。** 未确认版本进入 `concepts` 或 `candidates`；保留旧版本，不提前进入 `calibrated`、`approved` 或 Unity。

## 胶囊地面单位

- 身体正面朝上，脸和胸腹可见，头部朝画面右上，长轴约 `60°`。
- 胶囊必须平直、连续、短厚；不得弓曲、蜷缩、侧躺或变成细长条。
- 比较体量时只看身体核心。耳朵、手掌、脚掌、盾牌、匕首、法杖和长柄武器都不参与身体长宽判断。
- 不能为满足固定 `120×80` 技术区域而单轴压缩。若装备导致完整 AABB 超出，优先保留正确身体并将资产留在候选状态。
- 法师类最常见的失败是“包含法杖后看起来太长”，继而把身体压得过短；必须先隐藏或排除法杖再比较尸体本身。

## 球形飞行单位

- 球核保持近圆，可为表现落地重量做不超过约 `8%` 的轻微纵向压缩。
- 死亡球核不得大于已确认活体球核，建议目标约为活体核心的 `75%–85%`。
- 耳朵、脸、鼻口或其他头部线索朝画面右上；不能用正面水平构图消除方向，也不能画成长椭圆斜躺身体。
- 翅膀随头部方向旋转并瘫软贴地，翼尖靠近球核；不得保持飞行展开、上扬或拍动姿态。
- 球核尺寸只对比活体球核。翼展只用于画布安全和裁切检查，绝不参与缩放判断。

## 道具与特效

- 死亡道具必须与手掌分离，不得保留站立时的握持姿态。
- 经批准的单件道具可以贴近对应手掌，或像盾牌一样斜搭在下腹、胸侧等尸体表面；遮挡关系必须清晰。
- 法师法杖与羊魔长柄斧采用“斜搭下腹并与尸体重叠”的紧凑方案；死灵法师移除鬼火，只可保留已批准的紧凑匕首。
- 禁止自动补充第二件道具、鬼火、火焰球、光晕、粒子、烟雾、血迹或死亡特效。
- 道具既不能因为 AABB 校准而消失，也不能漂浮在尸体外侧扩大占用；如需独立掉落物，应另做独立 Sprite。

## 尺寸、AABB 与 Tile

- 母版保持 `256×256 RGBA`，预览为 `128×128 RGBA`；地面接触线继续以母版 `y=236` 为技术参考。
- 核心体量与完整 alpha AABB 是两套指标：核心决定角色胖瘦与尺度，完整 AABB 只检查裁切、安全边距和 Tile 占用。
- 不允许单轴拉伸。需要缩放时必须对角色、外部轮廓和道具整体等比缩放。
- 没有站立脚底的尸体使用完整可见尸体 AABB 中心对准 Tile 中心；球形飞行单位落地后也不再使用活体悬浮锚点。
- Tile QA 必须使用 `_128` 预览。需要放大检查时，Tile 与 Sprite 必须按相同比例同时缩放，禁止只放大角色。
- 每次 Review 同时展示已确认参考与当前候选，防止方向、核心体量或道具层级在连续迭代中漂移。

## 常见坑点

| 坑点 | 结果 | 修正 |
| --- | --- | --- |
| 把站立图直接旋转 | 身体仍像站立或产生弓背 | 以身份母图重建独立死亡姿态 |
| 把赤柴当成球形怪身体母图 | 蝙蝠变成长胶囊或出现错误四肢 | 赤柴对球形单位只提供头朝右上的方向 |
| 用完整 alpha AABB 比身体 | 法杖、盾牌、翼展导致错误缩放 | 只比较胶囊核心或球核 |
| 为缩短完整图而压缩身体 | 身体过短、过瘦或比例跳变 | 先隐藏道具比较核心，保持等比缩放 |
| 球核按翼展或完整 AABB 缩放 | 球体过大或过小 | 仅以已确认活体球核为基准 |
| 球形死亡图正面横放 | 没有与其他尸体一致的方向 | 保持球核近圆，让头部线索朝右上 |
| 道具仍被握住或漂浮 | 像攻击帧，且 AABB 过大 | 脱手后贴近手掌或压在尸体表面 |
| 保留鬼火、火焰或光效 | 死亡状态仍像施法 | 默认删除所有常驻职业特效 |
| 沿用站立脚底或飞行锚点 | 尸体在 Tile 上偏移 | 使用完整死亡尸体 AABB 中心 |
| 用 256 母版直接做 Tile QA | 占用被错误放大两倍 | 只用 `_128` 预览 |
| 缩小后不再清理色幕 | `_128` 出现精确绿/洋红残色 | 预览重采样后再次清理并运行校验器 |
| 未确认候选进入发布目录 | 后续被误当作正式母图 | 保持在 `concepts/candidates` 并保留版本历史 |

## Checklist

- [ ] 已先分类胶囊地面单位或球形飞行单位。
- [ ] 身份母图、死亡方向参考和编辑目标的职责已分别声明。
- [ ] 核心体量比较已排除耳、四肢、装备、翅膀和特效。
- [ ] 胶囊尸体平直短厚且头朝右上，或球形尸体保持近圆且头部线索朝右上。
- [ ] 批准保留的单件道具已脱手并紧凑贴合尸体；其他物件和特效已移除。
- [ ] 没有单轴拉伸，也没有为满足完整 AABB 牺牲核心体量。
- [ ] `_128` 预览已再次清理色幕残色，并以尸体 AABB 中心完成 Tile Review。
- [ ] 当前候选与已确认参考已并排比较。
- [ ] 未经人工确认的版本仍位于 `concepts` 或 `candidates`，未接入 Unity。
