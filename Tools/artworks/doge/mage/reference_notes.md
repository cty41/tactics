# 凯利蓝㹴法师动作姿态参考笔记

## Keep

- 唯一身份母图：`../calibrated/doge_capsule_mage_color_calibrated_v03.png`（down-right）与 `../calibrated/doge_capsule_mage_color_ul_v05.png`（up-left）。
- 紫灰胶囊身体、深色圆口鼻、短折耳、短脚掌、空手掌与单根蓝紫晶体法杖。
- 粗深棕轮廓、平涂色块和极少内部线条；目标是 Pure Run 小体量卡通 Sprite，不是像素画或精致插画。
- 身体中心 `x=128`、脚底基线 `y=236`；核心胶囊体量只与对应正式母图比较。

## Ignore

- 透明画布空白、运行时 Tile、阴影、Marker、血条、施法光环、投射物和命中特效。
- 参考动作中的长手臂、写实犬体、长袍、帽子、地面、透视背景和运动线。
- 任何历史 `rejected/superseded` 法师版本；反例只用于识别体量漂移，不能作为生成输入。

## Avoid Drift

- 不改变核心胶囊高度、宽度分布、折耳方向、口鼻大小、脚位或法杖长度。
- 不新增魔法帽、长袍、书、第二根法杖、光球、符文或职业挂件。
- 不让晶体法杖离手、复制、裁切或变成长柄武器。
- up-left 必须使用批准 UL 母图重建背向三分之四解剖，不能镜像 DR。
