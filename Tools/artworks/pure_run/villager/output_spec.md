# Pure Run 迷途村民 NPC 输出规格

## 用途

迷途村民事件中的 NPC：既作为 tile 场景摆件/事件对象，也作为护送达成的战斗 NPC 单位（替换现占位——目前战斗护送 NPC 复用 `unit.pure-run.mage` 法师图）。村民无攻击、无技能，只做 idle / hit / death 三族。

## 尺寸与锚点

- 母版 `256×256 RGBA`，核心胶囊中心 `x=128`，脚底基线 `y=236`；预览 `128×128`，基线 `y=118`。
- 胶囊体：圆形顶盖、近似平行侧壁、下段持平/内收；高度约 `122 px`（与已批准赤柴猎人同体量语言）。
- 无手臂策略：两只前爪与两只后爪以多像素接触面直接贴合主体边缘，禁止浮空、细线连接或可见臂/腿标签。
- Tile Review：脚底锚点精确对齐 `64×32` Tile 几何中心；hit/death 使用同基线。

## 身份

- 普通中华田园犬：黄褐色短毛、奶油色口鼻与胸腹，圆润面庞、简洁眼鼻；不穿服装，不带围巾、背带、首饰或其他饰品，无武器、无盾牌、无明显职业特征。
- 远离战士/法师/死灵/羊魔的身份特征；色板以暖土色、亚麻色为主，区别于队伍成员的饱和色。
- 不迁移任何已批准角色的配色或装备。

## 动作与状态

- Idle：放松站立，两爪着地。
- Hit：受击后仰/回缩的单帧漫画夸张（眼睛放大、身体后仰），不持械。
- Death：仰面平躺、头朝画面右上、身体轴约 `60°`、短厚平直，四爪保持与身体的连续软体轮廓，道具不脱手（无道具）；完整尸体 AABB 中心对齐 `64×32` Tile 中心。
- 不做 Melee / Cast / Ranged / Thrown 动作。

## 风格

- 粗深色外轮廓、扁平纯色块、稀疏内部线，与项目胶囊单位语言一致。
- 无渐变、无镜面高光、无像素噪点、无地面阴影（运行时用统一单位阴影）。
- 透明背景、无文字、无水印、无 UI。
- 生成使用均匀纯 `#00ff00` 色幕；图形内部不得出现该颜色。

## Review

- 每姿态 `128×128` 预览 + `64×32` Tile 线框，逐张人工确认后才进入下一张（遵循一次一图）。
- DR 与 UL 需同一体量：核心蒙版排除耳/口鼻/爪/装备后上缘、下缘、中心、最大宽度误差 ≤2–3 px。

## 命名

`pure_run_villager_<pose>_<direction>_vNN.png`，方向 `dr|ul`；`_128` 预览成对。死亡图无方向后缀。
