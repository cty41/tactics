# Pure Run tile 道具输出规格

## 用途

Adventure Board tile 场景中的交互摆件：休息点篝火、商店商人、宝箱两态、堕落祭坛、出口传送门。除堕落祭坛外，均为 256×256 母版、底部基线 y=236、脚底锚点对齐 `64×32` Tile 几何中心；道具不转向，各只画一张 DR 单帧。堕落祭坛是 `2×2` Tile 大型场景资产，使用 384×384 母版、水平中心 x=192、底部基线 y=354。

## 尺寸与锚点

- 母版 `256×256 RGBA`，摆件底部基线 `y=236`（脚底对齐 Tile 几何中心）；完整轮廓高度约 `100–160 px`（商人可到约 180px，人物形道具与角色同尺度）。
- 预览 `128×128 RGBA`，基线 `y=118`；Tile Review 使用真实 `64×32` 错列等距排布。
- 堕落祭坛例外：母版 `384×384 RGBA`，水平中心 `x=192`、底部基线 `y=354`，整体构图占据 `2×2` Tile；其神像高度约为普通胶囊体单位的 `1.6–2` 倍。预览仍输出 `128×128 RGBA`，用于目录和快速审阅，不作为实际尺寸对比依据。
- 道具只画 DR（右下）单帧，不做 UL/镜像（道具不参与四向显示；出口传送门同样单帧）。

## 风格

- 粗深色外轮廓、扁平纯色块、少量内部结构线；与已批准角色语言一致。
- 无渐变、无镜面高光、无柔和光照、无像素噪点、无地面阴影（运行时用统一单位阴影）。
- 透明背景、无文字、无水印、无 UI。
- 生成使用均匀纯 `#00ff00` 色幕；图形内部不得出现该颜色。

## Review

- `128×128` 预览 + Tile 线框：确认摆件与角色同屏时比例正确、不悬浮不下沉、可辨识。
- 商人立姿与交易反馈两张同屏对比：身份一致、姿态差异清晰。
- 宝箱闭合/打开两张同屏对比：同一箱体语言、状态差异明确（闩、盖、内容）。

## 命名

`pure_run_prop_<type>_vNN.png`，母版与 `_128` 预览成对；`vNN` 自 `v01` 起递增。
