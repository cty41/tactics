# Pure Run Iron Helmet V2

Redraw the V1 helmet in the established approved Pure Run item style. Preserve the plain open-face iron helmet concept and isometric three-quarter orientation, but replace the semi-realistic polished-metal rendering with flat matte gray color blocks, broad soft shading, minimal highlights, and a compact rounded silhouette. Remove most rivets and small construction detail. Use a clean dark outline consistent with approved weapons and potions. No wearer, decoration, shadow, glow, or UI. Pure `#00ff00` background.
