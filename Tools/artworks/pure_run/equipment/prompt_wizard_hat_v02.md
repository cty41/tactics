# Pure Run Wizard Hat V2

Redesign the V1 wizard hat in the established approved Pure Run item style. Keep the broad brim and bent crown, but make the silhouette shorter, rounder, and slightly chunky for a compact dog character. Use flat matte muted blue-purple color blocks, broad soft shading, minimal highlights, a simple band, and a clean dark outline. Remove realistic cloth modeling, excessive folds, and dramatic lighting. No symbols, particles, shadow, glow, wearer, or UI. Pure `#00ff00` background.
