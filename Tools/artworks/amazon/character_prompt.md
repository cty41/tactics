# Amazon Character Prompt

## Character Contract

```text
Character contract:
an amazon female warrior with blonde hair tied in a high ponytail.
She wears a short red tunic with simple gold trim.
She carries one javelin and one round shield.
She has a compact fantasy battle-unit appearance.
Keep the design simple, readable, and suitable for a low-resolution isometric RPG sprite.

Equipment constraints:
one javelin only
one round shield only
no extra weapon
no cape
no extra accessories
no complex armor pieces

Face constraints:
keep facial features extremely minimal, with large dark block-like eyes and no visible nose or mouth.
```

## Consistency Contract

```text
Consistency constraints:
preserve the exact same character identity, same body proportions, same face style, same outfit shape, same colors, same javelin design, same shield design, same pixel density, same camera angle, same framing, and same scale.
```

## Usage Notes

- Reuse this block after the base style prompt.
- Keep equipment wording singular to reduce duplicate-weapon drift.
- If later variants need different gear, update this file first and keep action files focused on motion only.
