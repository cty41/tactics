## Skills to Implement
1. **Fireball**
   - **Effect**: 范围内造成伤害，并点燃受伤单位
   - **Range**: 4tiles
   - **AOE Range**：目标tile和相邻的4个tiles.
   - **Cost**: 3 Mana
   - **点燃**：后续3回合每回合造成1点伤害

2. **近战治疗**
    - **Cost**: 无
   - **Effect**: 对相邻友方单位治疗3点HP
   - **Range**: 1 tiles.

3. **远程攻击**
   - **Effect**: 对范围内的单个unit造成伤害
   - **Cost**: 无
   - **Range**: 5 tiles.攻击者相邻1tiles不可攻击
  
 4. **近战攻击**
   - **Effect**: 对范围内的单个unit造成伤害
   - **Cost**: 无
   - **Range**: 5 tiles.攻击者相邻1tiles不可攻击


## Implementation Plan
1. **Design and Prototyping**
   - Create detailed designs for each skill, including effects, mechanics, and visuals.
   - Develop prototypes for each skill to test and refine mechanics.

2. **Development**
   - Implement the skills in the game codebase.
   - Ensure skills are integrated with the existing combat system.
   - Add visual and audio effects for skill usage.

3. **Testing and Balancing**
   - Conduct extensive testing to ensure skills are balanced and fun to use.
   - Adjust mechanics and effects based on feedback from playtesting.

4. **Documentation**
   - Document the implementation details and usage of each skill.
   - Provide guidance for future updates and modifications.
