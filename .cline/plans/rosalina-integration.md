# Rosalina 接入计划

## 概述

将 [Rosalina](https://github.com/Eastrall/Rosalina) (v4.0.0) 接入当前 Unity 6 项目。Rosalina 是一个 UI Toolkit 代码生成工具，可根据 UXML 模板自动生成 C# 绑定脚本。

---

## 一、兼容性评估

### 1.1 兼容项 ✅

| 项目 | 当前项目 | Rosalina 要求 | 状态 |
|------|----------|---------------|------|
| Unity 版本 | 6000.3.11f1 (Unity 6) | ≥ 2021.3 | ✅ 兼容 |
| API 兼容性 | .NET Standard 2.1 | .NET Standard 2.0 | ✅ 向后兼容 |
| 平台 | 多平台 | Editor-only 工具 | ✅ 无冲突 |
| 不安全代码 | 仅 Odin 模块启用 | 不需要 | ✅ 无冲突 |

### 1.2 潜在问题 ⚠️

| 问题 | 风险等级 | 说明 |
|------|----------|------|
| **Roslyn DLL 版本冲突** | 🟡 中 | Rosalina 自带 `Microsoft.CodeAnalysis.dll` (v4.2.0)，当前项目已有 Roslyn 用于代码分析。需要检查版本是否一致。 |
| **UI Toolkit 使用** | 🟢 低 | Rosalina 依赖 `UnityEngine.UIElements`，当前项目主要使用 uGUI (`com.unity.ugui`)，但不冲突。 |
| **ScriptableSingleton** | 🟢 低 | Rosalina 使用 `ScriptableSingleton<T>` 存储设置，在 Unity 6 中可用。 |

### 1.3 DLL 冲突分析

**当前项目 Roslyn 引用** (`Tactics.CodeAnalysis.asmdef`):
```json
"precompiledReferences": [
    "Microsoft.CodeAnalysis.dll",
    "Microsoft.CodeAnalysis.CSharp.dll",
    "System.Collections.Immutable.dll",
    "System.Reflection.Metadata.dll",
    "System.Runtime.Loader.dll",
    "Newtonsoft.Json.dll"
]
```

**Rosalina Roslyn 引用** (`com.eastylabs.rosalina.asmdef`):
```json
"precompiledReferences": [
    "Microsoft.CodeAnalysis.dll",
    "Microsoft.CodeAnalysis.CSharp.dll"
]
```

**结论**：两个项目都引用了相同的 Roslyn DLL，但 Unity 会统一加载。当前项目通过 `com.unity.code-analysis` 包提供这些 DLL，Rosalina 自带 v4.2.0 版本。

**解决方案**：
- 安装 Rosalina 后，如果版本不一致，删除 Rosalina 的 `Editor/Plugins/` 下的 Roslyn DLL
- 让两个 asmdef 共用 `com.unity.code-analysis` 提供的版本
- 或在 Rosalina 的 asmdef 中添加 GUID 引用指向项目的 DLL

## 二、接入步骤

### Step 1: 安装 Rosalina 包

**方式选择**（推荐 OpenUPM，因为项目已配置 scoped registry）：

```bash
openupm add com.eastylabs.rosalina
```

或手动添加到 `Packages/manifest.json`：
```json
"dependencies": {
    "com.eastylabs.rosalina": "4.0.0"
}
```

> 项目已配置 `package.openupm.com` scoped registry，可直接使用 OpenUPM 安装。

### Step 2: 解决 Roslyn DLL 冲突

Rosalina 自带 10 个 DLL（含 Roslyn v4.2.0），当前项目已通过 `com.unity.code-analysis` 提供 Roslyn DLL。

**推荐方案**：删除 Rosalina 的 `Editor/Plugins/` 文件夹中的所有 Roslyn 相关 DLL，让 Rosalina 的 asmdef 引用项目已有的版本。

需要删除的 DLL：
- `Microsoft.CodeAnalysis.dll`
- `Microsoft.CodeAnalysis.CSharp.dll`
- `System.Collections.Immutable.dll`
- `System.Reflection.Metadata.dll`
- 其他 System.* 依赖 (如果项目中已有)

**或者**：修改 Rosalina 的 `.asmdef`，移除 `precompiledReferences`，添加 GUID 引用指向 `com.unity.code-analysis` 的 DLL。

### Step 3: 配置 Rosalina

1. 打开 `Edit > Project Settings > Rosalina`
2. 启用自动生成
3. 配置需要生成绑定的 UXML 文件路径

### Step 4: 验证编译

1. 运行 Rosalina 生成测试绑定
2. 检查编译是否通过
3. 运行现有测试确保无回归

## 三、使用方法

### 3.1 基本工作流

```
1. 创建 UXML 文件 (e.g., MainMenu.uxml)
2. 在 UXML 中为元素命名 (name="confirm-button")
3. Rosalina 自动生成 MainMenu.g.cs 绑定文件到 Assets/Rosalina/AutoGenerated/
4. 在代码中使用生成的绑定类
```

### 3.2 命名转换规则

| UXML name 属性 | 生成的 C# 属性名 |
|----------------|------------------|
| `confirm-button` | `ConfirmButton` |
| `health_bar` | `HealthBar` |
| `title` | `Title` |
| `player-score` | `PlayerScore` |

### 3.3 生成的代码结构

```csharp
// MainMenu.g.cs - 自动生成，不要手动修改
using UnityEngine;
using UnityEngine.UIElements;

public partial class MainMenu : MonoBehaviour
{
    // 自动生成的属性
    public Label TitleLabel { get; private set; }
    public Button StartButton { get; private set; }
    public Button SettingsButton { get; private set; }
    
    // 绑定方法 - 在 OnEnable 或合适时机调用
    public void BindTo(UIDocument document)
    {
        var root = document.rootVisualElement;
        TitleLabel = root.Q<Label>("title-label");
        StartButton = root.Q<Button>("start-button");
        SettingsButton = root.Q<Button>("settings-button");
    }
}

// 使用方式
public partial class MainMenu : MonoBehaviour
{
    private void OnEnable()
    {
        BindTo(GetComponent<UIDocument>());
        
        StartButton.clicked += OnStartClicked;
        SettingsButton.clicked += OnSettingsClicked;
    }
    
    private void OnStartClicked() { /* ... */ }
    private void OnSettingsClicked() { /* ... */ }
}
```

### 3.2 三种生成器类型

#### 类型 1: Document (运行时 UI)

```csharp
// MainMenu.uxml
<ui:VisualElement name="root">
    <ui:Label name="title" text="Main Menu" />
    <ui:Button name="start-button" text="Start" />
</ui:VisualElement>

// 生成: MainMenu.g.cs
public partial class MainMenu : MonoBehaviour
{
    public Label Title { get; private set; }
    public Button StartButton { get; private set; }
    
    private void OnEnable()
    {
        StartButton.clicked += OnStartClicked;
    }
}
```

#### 类型 2: Component (可复用组件)

```csharp
// HealthBar.uxml
<ui:VisualElement name="root">
    <ui:ProgressBar name="health-bar" />
    <ui:Label name="health-text" />
</ui:VisualElement>

// 生成: HealthBar.g.cs
public partial class HealthBar
{
    public ProgressBar HealthBar { get; private set; }
    public Label HealthText { get; private set; }
    
    public HealthBar(VisualElement root) { /* 绑定 */ }
}
```

#### 类型 3: EditorWindow (编辑器窗口)

```csharp
// LevelEditor.uxml
<ui:VisualElement name="root">
    <ui:Button name="save-button" />
</ui:VisualElement>

// 生成: LevelEditor.g.cs
public partial class LevelEditor : EditorWindow
{
    public Button SaveButton { get; private set; }
    
    private void CreateGUI() { /* 绑定 */ }
}
```

### 3.3 项目配置

在 `Project Settings > Rosalina` 中：
- **Enable Generation**: 全局开关
- **Per-file Settings**: 为每个 UXML 配置生成类型 (Document/Component/EditorWindow)

### 3.4 自定义组件支持

```xml
<!-- 在 UXML 中使用自定义组件 -->
<ui:Instance name="health-bar" type="HealthBar" />
```

Rosalina 会在生成的代码中自动初始化该组件：
```csharp
HealthBar = new HealthBar(Root.Q<VisualElement>("health-bar"));
```

## 四、与现有 UI 系统集成

### 4.1 当前 UI 架构

- 现有 UI 使用 `UIManager.cs` 管理 uGUI
- 使用 `GameAssetManager` 加载 UI prefab
- UI 控制器继承自基类（如 `GUIController.cs`）

### 4.2 UI Toolkit 基类扩展

Rosalina 生成的 `Document` 类型是 `MonoBehaviour`，可以继承项目现有 UI 基类：

```csharp
// 生成的绑定文件
public partial class NewGameUI : MonoBehaviour
{
    public Button StartButton { get; private set; }
    public Label TitleLabel { get; private set; }
    
    private void OnEnable()
    {
        var doc = GetComponent<UIDocument>();
        StartButton = doc.rootVisualElement.Q<Button>("start-button");
        TitleLabel = doc.rootVisualElement.Q<Label>("title-label");
    }
}

// 项目中的控制器（同一个 partial class）
public partial class NewGameUI : GameUIControllerBase
{
    protected override void Initialize()
    {
        StartButton.clicked += OnStartClicked;
    }
}
```

### 4.3 集成方案

```csharp
// 混合使用 uGUI 和 UI Toolkit
public class HybridUIManager : MonoBehaviour
{
    private async Task LoadUIToolkitUI(string uiPath)
    {
        // 通过 Rosalina 生成的绑定类操作 UI Toolkit
        var document = FindObjectOfType<UIDocument>();
        var bindings = new GeneratedUIBinding(document.rootVisualElement);
        
        // 使用类型安全的绑定
        bindings.StartButton.clicked += HandleStart;
    }
}
```

### 4.3 建议的迁移策略

1. **新功能**优先使用 UI Toolkit + Rosalina
2. **现有 uGUI** 保持不变，逐步迁移
3. **共存**：两种 UI 系统可同时工作

## 五、风险与备选方案

| 风险 | 缓解措施 |
|------|----------|
| DLL 版本冲突 | 删除 Rosalina 自带 DLL，使用 Unity 内置版本 |
| 与现有 UI 冲突 | UI Toolkit 和 uGUI 独立，无运行时冲突 |
| 生成代码质量 | 生成代码为 partial class，可直接扩展 |
| 维护性 | Rosalina 最后更新 2023 年，可能需要 fork 维护 |
